## 1. Visual Style Brief (shared across all assets)

All 5 raster assets share a unified visual language:

- **Subject:** Stylized kitsune fox face/portrait — close-up, anime-inspired, expressive. Not full-body character.
- **Background:** Very dark near-black (`#0a0a0a` / `#0E0E0E`) — matches the app's dark-first identity.
- **Accent palette:** Orange/amber glow tones (echo `--color-grammar-adverb: #f97316`, warm orange). The fox-mark in the nav uses this warm orange; raster art should echo this warmth.
- **Style:** Semi-illustrated (not photorealistic, not fully cel-shaded) — anime character card aesthetic at high resolution.
- **Music tie-in:** Subtle — a small musical note or audio waveform element in the composition, not the focal point.

## 5. Post-Generation Instructions

After generating all 4 images (`logo.png`, `apple-touch-icon.png`, `og-image.png`, `twitter-image.png`):

**Step 1: Place files in `public/`**
```
public/logo.png               (512×512, transparent background)
public/apple-touch-icon.png   (180×180, opaque dark background)
public/og-image.png           (1200×630, opaque dark background)
public/twitter-image.png      (1200×630 — may copy from og-image.png)
```

**Step 2: Verify dimensions and alpha channels**
```bash
npx tsx --tsconfig tsconfig.scripts.json scripts/brand/verify-brand-assets.ts
```
The verify script checks each file against expected dimensions and reports alpha-channel issues (apple-touch-icon must have opaque background).

**Step 3: Synthesize favicon.ico from logo.png**

> **IMPORTANT:** logo.png must be exactly 512×512 before running this script. The script will error if dimensions are wrong.

```bash
npx tsx --tsconfig tsconfig.scripts.json scripts/brand/synthesize-favicon.ts
```

This synthesizes `public/favicon.ico` containing 16×16 and 32×32 PNG frames using `sharp` (available as Next.js transitive dep). The ICO uses manual binary construction — `sharp` v0.34.5 has no native `.ico()` method.

**Step 4: Fix any reported issues**

The verify script will report dimension mismatches or alpha-channel issues. Fix reported issues before committing to git.

**Step 5: Commit the new public/ assets**
```bash
git add public/logo.png public/apple-touch-icon.png public/og-image.png public/twitter-image.png public/favicon.ico
git commit -m "feat(14.5-02): replace brand raster assets with kitsune fox art"
```
