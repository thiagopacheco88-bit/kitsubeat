## 1. Visual Style Brief — Mascot Direction

All assets share this visual language. **Upload the mascot reference image alongside each prompt** (the crimson fox face with headphones and neon glow circle).

- **Subject:** Crimson/dark-red fox mascot face — close-up portrait, cartoon vector style
- **Headphones:** Red over-ear headphones with power button symbols on earcups
- **Details:** White chest/muzzle fur, expressive dark eyes, subtle smirk
- **Floaters:** Music notes and binary code digits (0s and 1s) floating in the background
- **Background:** Very dark near-black (`#0a0a0a` / `#0E0E0E`)
- **Style:** Clean cell-shaded vector illustration — gaming mascot / esports aesthetic. Not anime watercolor. Not photorealistic.
- **Glow:** Optional soft pinkish-red neon glow ring around the subject

### logo.png — 512×512, transparent background

```
Using the attached mascot image as style reference, recreate the KitsuBeat fox mascot
as a standalone icon with a TRANSPARENT background — no dark circle, no glow ring,
no frame. Just the fox head and red headphones floating against transparency.

Style: clean vector cell-shading, crimson/dark-red fox, white muzzle fur,
red over-ear headphones with power button icons on earcups, music notes and
faint binary code floating around the subject.

Output: 512×512 pixels, PNG with transparent background.
```

---

### apple-touch-icon.png — 180×180, opaque dark background

```
Using the attached mascot image as style reference, recreate the KitsuBeat fox mascot
as a 180×180 square app icon. Solid dark background color #0a0a0a — NO transparency,
NO circle glow ring. Fox head and headphones centered and tightly cropped to fill
most of the square.

Style: clean vector cell-shading, crimson/dark-red fox, white muzzle fur,
red headphones with power button icons, music notes around the subject.

Output: 180×180 pixels, PNG with fully opaque background (#0a0a0a).
```

### og-image.png — 1200×630, dark background + wordmark

```
Using the attached mascot image as style reference, create a 1200×630 social media

Style: clean vector/gaming aesthetic, no transparency, professional app store banner look.

Output: 1200×630 pixels, PNG, fully opaque background.
```

## 4. Post-Generation Instructions

After generating `logo.png`, `apple-touch-icon.png`, `og-image.png`:

**Step 1 — Place files**
```
public/logo.png               (512×512, transparent)
public/apple-touch-icon.png   (180×180, opaque dark)
public/og-image.png           (1200×630, opaque dark + wordmark)
```

**Step 2 — Copy og-image → twitter-image**
```bash
cp public/og-image.png public/twitter-image.png
```

**Step 3 — Verify all assets**
```bash
npx tsx --tsconfig tsconfig.scripts.json scripts/brand/verify-brand-assets.ts
```
Expect 5 `OK:` lines and `All brand asset checks passed.`

**Step 4 — Fix apple-touch-icon alpha if needed**

If the verify script reports alpha channel on apple-touch-icon.png, flatten it:
```bash
npx tsx --tsconfig tsconfig.scripts.json -e "import sharp from 'sharp'; sharp('./public/apple-touch-icon.png').resize(180,180).flatten({background:'#0a0a0a'}).png().toFile('./public/apple-touch-icon-fixed.png').then(()=>console.log('done'))"
```
Then replace: `mv public/apple-touch-icon-fixed.png public/apple-touch-icon.png`

**Step 5 — Synthesize favicon** (requires logo.png to be exactly 512×512 first)
```bash
npx tsx --tsconfig tsconfig.scripts.json scripts/brand/synthesize-favicon.ts
```
Expect: `OK: public/favicon.ico written (XXXX bytes, magic: 0x00010000)`

**Step 6 — Commit**
```bash
git add public/logo.png public/apple-touch-icon.png public/og-image.png public/twitter-image.png public/favicon.ico
git commit -m "feat(14.5-02): replace brand raster assets with kitsune fox mascot art"
```
