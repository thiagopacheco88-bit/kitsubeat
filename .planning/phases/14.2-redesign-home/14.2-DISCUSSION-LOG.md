## Continue Learning Data Shape

### Sub-decision 1: WHERE-clause filter (which rows count as "in-progress")

| Option | Description | Selected |
|--------|-------------|----------|
| `completion_pct > 0` (single column) | `completion_pct` is set whenever any exercise group is attempted (per saveSessionResults). Cleanest single-column filter. | ✓ |
| 3-column OR (`vocab_track_pct > 0 OR grammar_track_pct > 0 OR kanji_track_pct > 0`) | Matches SPEC's "any non-zero per-track progress" wording literally. Verbose; no semantic gain. | |
| Any `ex*_best_accuracy IS NOT NULL` | Lenient — includes attempts that didn't move tracks (first-attempt failures). False-positive risk. | |

**Recorded as D-01.**

### Sub-decision 2: Progress-bar fill source

| Option | Description | Selected |
|--------|-------------|----------|
| `completion_pct * 100` (clamped 1%–100%) | Canonical "how far through the lesson" signal. Matches what a progress bar conventionally means. | ✓ |
| SQL avg-of-3-tracks `(COALESCE(vocab_track_pct,0) + COALESCE(grammar_track_pct,0) + COALESCE(kanji_track_pct,0)) / 3.0` | Right metric for the Star 3 unlock gate (Phase 11.6). Wrong metric for "where am I in this lesson." | |
| Single-track choice (e.g., always `vocab_track_pct`) | Arbitrary which track represents lesson-progress. | |

**Recorded as D-02.**

### Sub-decision 3: Returned shape + ordering + limit

| Option | Description | Selected |
|--------|-------------|----------|
| `{slug, title, artist, anime, youtube_id, jlpt_level, completion_pct, updated_at}`, sort `updated_at DESC`, limit=3 | Mirrors `getFeaturedSongs` shape; future shared CardLink could consume both. SPEC §Req 4 specifies limit=3. | ✓ |
| Bare-minimum shape (drop jlpt_level) | Smaller payload but breaks parity with featured query. | |
| Joined-progress-detail shape (include all 3 track percents + ex*_best_accuracy) | Heavier; only completion_pct is rendered. | |

**Recorded as D-03.**

### Sub-decision 3: console.warn signal

| Option | Description | Selected |
|--------|-------------|----------|
