## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Test 4 selector matched nested child testids**
- **Found during:** Task 1 GREEN phase (Test 4 failure)
- **Issue:** `querySelectorAll('[data-testid^="continue-card-"]')` returned 15 elements instead of 3 — nested child elements (play-overlay, aura, stars, title-jp, progress-fill, placeholder) all start with `continue-card-`, so the prefix query matched them all
- **Fix:** Replaced querySelectorAll + length check with `getByTestId` per card + `compareDocumentPosition` to verify DOM ordering. Behavioral intent (newest first, oldest last) fully preserved.
- **Files modified:** `src/app/components/home/ContinueLearning.test.tsx`
- **Commit:** 99499e3 (fix incorporated into same GREEN commit)

**2. [Rule 2 - Null safety] anime prop null coalesced in ContinueLearning**
- **Found during:** Task 1 — reviewing getContinueLearning return type from Plan 02
- **Issue:** `getContinueLearning` returns `anime: string | null` (Plan 02 SUMMARY confirms). ContinueCard expects `anime: string` (not nullable). Without coalescing, TypeScript would flag the mismatch.
- **Fix:** Pass `anime={row.anime ?? ""}` to ContinueCard. Behavioral impact: cards with null anime display an empty subtitle line rather than crashing.
- **Files modified:** `src/app/components/home/ContinueLearning.tsx`
- **Commit:** 99499e3
