## Token-Literal Disposition

**No lint allowlist needed.** The `kitsubeat-tokens/no-raw-tokens` ESLint rule checks only `className` strings — it does NOT inspect inline `style` props. All rgba literals land in inline styles:

| Usage | Location | Reason |
|-------|----------|--------|
| `rgba(255,255,255,0.85)` | PLAY badge background (inline style) | Semi-transparent white CTA-pill; no matching `var(--*)` token exists for this opacity |
| `rgba(0,0,0,0.75)` | Vignette gradient (inline style) | Progressive bottom-fade overlay; literal embedded in linear-gradient string |
| `rgba(0,0,0,0.65)` | JP title textShadow (inline style) | Text legibility shadow; theme-independent near-black |
| `rgba(255,255,255,0.85)` | Anime subtitle text color (inline style) | Muted white text over cover image |

**Lint violations fixed (D-12 compliance):**
1. `text-white` (bare) → moved to `style={{ color: "white" }}` (Rule 2 auto-fix: token discipline)
2. `h-[3px]` (arbitrary px) → moved to `style={{ height: "3px" }}`
3. `text-[11px]` (arbitrary px) → replaced with `text-xs` (12px, close enough for anime subtitle line)

Result: `npx eslint src/app/components/home/ContinueCard.tsx` reports 0 errors, 1 warning (`no-img-element` — same warning present in analog PathNode.tsx; accepted per established precedent).
