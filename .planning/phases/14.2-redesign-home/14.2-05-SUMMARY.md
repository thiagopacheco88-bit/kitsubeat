# Phase 14.2 Plan 05: SectionHeader + Carousel Primitives Summary

**One-liner:** Extracted reusable `<SectionHeader>` (server) and `<Carousel>` (client-island) home primitives with scroll-snap and Noto Sans JP eyebrow titles.

## What Was Built

### SectionHeader (`src/app/components/home/SectionHeader.tsx`)

Pure-display server component that renders the section header strip used across all 4 home narrative sections.

**Prop signature:**
```typescript
interface SectionHeaderProps {
  titleJp: string;   // e.g., "続ける" — rendered with var(--font-jp)
  title: string;     // e.g., "Continue Learning"
  viewAll?: string;  // optional href; link omitted when undefined
  testId?: string;   // optional data-testid on root
}
```

**Key implementation details:**
- Japanese title rendered in `<span>` with `style={{ fontFamily: "var(--font-jp)" }}` and `data-testid="section-header-title-jp"`
- `viewAll` link uses `text-[var(--color-text-muted)]` with hover to `text-[var(--color-text)]`
- Zero raw hex — 6 `var(--` token references total
- Pure server component (no `'use client'` directive)

### Carousel (`src/app/components/home/Carousel.tsx`)

Client-island scroll-snap container for all home card rows.

**Prop signature:**
```typescript
interface CarouselProps {
  children: React.ReactNode;
  testId?: string;     // optional data-testid on root
  ariaLabel?: string;  // optional; sets aria-label + role="region"
}
```

**Key implementation details:**
- `"use client"` on line 1 — client-island designation per CONTEXT D-09
- CSS contract: `flex gap-3 overflow-x-auto pb-4 scrollbar-thin snap-x snap-mandatory px-4`
- `role="region"` applied conditionally only when `ariaLabel` is set
- Zero raw hex, no `disabled` attribute, no `pointer-events: none` (M1 invariant)
