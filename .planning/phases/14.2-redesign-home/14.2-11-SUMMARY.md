## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] GlobalLearnedCounter omitted from MobileNavSheet**
- **Found during:** Task 2 GREEN phase (vitest run revealed React error)
- **Issue:** `GlobalLearnedCounter` is an `async` server component. Next.js correctly errors when you import an async server component inside a `"use client"` island. The plan's implementation sketch included `<GlobalLearnedCounter />` at the bottom of the sheet.
- **Fix:** Removed `GlobalLearnedCounter` from the sheet entirely. The word-count metric is still visible on desktop (in the `hidden sm:contents` cluster) and the `/vocabulary` route is accessible via the Progress link in the sheet.
- **Files modified:** `src/app/components/MobileNavSheet.tsx`
- **Commit:** de9b9b0

**2. [Rule 1 - Bug] focus() called synchronously instead of via setTimeout**
- **Found during:** Task 2 GREEN phase (test 5 "close button returns focus" failed)
- **Issue:** `setTimeout(() => triggerRef.current?.focus(), 0)` does not flush within `act()` in jsdom
- **Fix:** Changed to synchronous `triggerRef.current?.focus()` in the `close` function — functionally equivalent in a real browser (state update batching doesn't affect focus in this flow)
- **Files modified:** `src/app/components/MobileNavSheet.tsx`
- **Commit:** de9b9b0
