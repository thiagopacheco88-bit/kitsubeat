# Phase 14.2: Redesign Home (/) — Specification

**Created:** 2026-05-03
**Ambiguity score:** 0.13 (gate: ≤ 0.20)
**Requirements:** 9 locked

## Goal

Apply the **CA-hybrid** design language matured on `/path` (cover-art-bleed nodes + lantern-streak chip + hero-block + auras) to the home route `/`, swap the flat 5-carousel catalog for a personalization-aware narrative (HeroFeatured → Continue Learning auth-only → Foundations → Browse by Anime → Featured Songs), and promote the `KitsuBeat` wordmark + `<LanternStreak>` chip out of `/path` into the global `RootLayout` header so the streak is visible on every surface.

## Background

`/` is the brand-defining first impression — what recruiters, interviewers, and new users see first. Phase 14.1 just shipped the post-`/path` design vocabulary (CA-hybrid: cover-art-as-background, lantern streak, hero-progress block, auras, sticky CTAs); this phase carries that vocabulary into the home surface and the global header.

**What exists today (master HEAD, post-14.1):**
- [src/app/page.tsx](src/app/page.tsx) — server component: parallel-fetches `getFeaturedSongs(12)` + `getTopAnimeFranchises(20)` + `getBeginnerSongs(12)` + `getRecentSongs(12)` + `getTopArtists(12)`. Renders an inline `<MediaCard>` (220px tile, `mqdefault.jpg` thumbnail with bottom-fade gradient) inside an inline `<Carousel>`. **Five flat carousels — no auth-awareness, no personalization, no streak chip, no Continue Learning, no Foundations on home.** Static text hero ("Learn Japanese through anime songs") with two browse CTAs.
- [src/app/layout.tsx](src/app/layout.tsx) — sticky header (`max-w-6xl`) with `/logo.png` + `KitsuBeat` wordmark, nav links (`Path | Songs | Kana | Progress | Profile | Admin?`), `<GlobalLearnedCounter>`, `Sign in`/`UserButton`, `<ThemeToggle>`. Path link added inline 2026-05-03 ([fc68c50](commit:fc68c50)) ahead of this phase formalizing its design treatment.

## Constraints

- **Token system (hard):** Every new color / shadow / spacing / radius / motion value MUST resolve to a `var(--*)` token. The `kitsubeat-tokens` ESLint plugin must report 0 violations across changed files. **No new tokens** are needed — the four 14.1-shipped tokens (`--shadow-cta-red`, `--shadow-hero-glow`, `--aura-color`, `--mist-fill`) and three keyframes (`ka-pulse`, `ka-flicker`, `ka-aura`) cover this phase's needs.
- **Both themes (hard):** Every new component MUST render correctly in both dark (default) and light themes. Manual visual check at both themes required before merge. Cover-art components MUST tolerate cover-image-failed-to-load (broken `youtube_id`) without exposing raw `var(--color-bg)` as the only visible surface.
- **Reduced-motion (hard):** New consumption sites of `ka-pulse` (ContinueCard PLAY ▶) and `ka-aura` (FoundationCard 3-star halo) MUST honor the existing global `@media (prefers-reduced-motion: reduce)` override. Reduced-motion Playwright spec MUST cover both new sites.
- **M1 invariant carry-over (hard):** No `disabled` attribute, no `pointer-events: none` on any interactive node — including `FoundationCard` locked state. Vignette / mist overlays MUST set `pointer-events: none` so taps fall through to the underlying link.
- **Mobile-first (hard):** Baseline viewport 390×844 (iPhone 14 Pro). All tap targets ≥44px (Phase 14 SPEC AC #11 carry-over). HeroFeatured CTA button ≥56px.
- **Cross-surface header coherence (hard):** Promoting `<LanternStreak>` to the global header MUST NOT double-render the streak on `/path`. `/path` page MUST render exactly one wordmark and exactly one streak chip post-merge.
- **Bundle budget (soft):** `/` is not on the Phase 13 50KB list. Capture `/` First Load JS pre/post in plan-phase verification; soft target ≤+12KB regression. If exceeded, plan-phase must propose a mitigation (lazy-load Continue Learning, defer carousel snap CSS, etc.).
- **Data shape (hard):** No changes to `GamificationState` shape, `SongListItem` shape, `useKanaProgress` store, or the `user_song_progress` schema. New components consume existing data shapes; the new `getContinueLearning(userId, limit)` query reads from existing tables only.
- **Anonymous-catalog clean (hard):** Unauthenticated visitors MUST NOT see Continue Learning section, MUST NOT see star/mastery decorations on Featured Songs CoverCards, MUST NOT see streak chip. Same `showProgress`-style gate that SongCard already enforces.
- **Accessibility (hard):** axe-core score ≥95 on `/` post-redesign in both themes (Phase 14 SPEC AC #12 carry-over). All decorative SVGs `aria-hidden="true"`; `<LanternStreak>` exposes `aria-label="{N}-day streak"`; HeroFeatured `<img>` has `alt={song.title}`.
- **Hero failure mode (hard):** Hero MUST never throw or render an empty state when `current_path_node_slug` is null OR points to a delisted song. It MUST gracefully fall through to top `getFeaturedSongs(1)` with adapted CTA copy and server-side `console.warn`. Same pattern as 14.1's `getStarterSongs()` repair.
