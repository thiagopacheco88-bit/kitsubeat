### `src/lib/db/queries.ts::getContinueLearning` (db-query, CRUD read)

**Analog: `getFeaturedSongs`** (queries.ts lines 316–345)

**Drizzle select shape with correlated youtube_id subquery** (queries.ts lines 316–345):
```typescript
export async function getFeaturedSongs(limit: number = 6) {
  return db
    .select({
      id: songs.id,
      slug: songs.slug,
      title: songs.title,
      artist: songs.artist,
      anime: songs.anime,
      youtube_id: sql<string | null>`(
        SELECT sv.youtube_id FROM song_versions sv
        WHERE sv.song_id = songs.id AND sv.youtube_id IS NOT NULL
        ORDER BY CASE sv.version_type WHEN 'tv' THEN 0 ELSE 1 END
        LIMIT 1
      )`,
      jlpt_level: songs.jlpt_level,
      difficulty_tier: songs.difficulty_tier,
    })
    .from(songs)
    .where(sql`EXISTS (
      SELECT 1 FROM song_versions sv
      WHERE sv.song_id = ${songs.id} AND sv.lesson IS NOT NULL
    ) AND ${songs.language} = 'ja'
    AND ${songs.quality_status} = 'active'
    AND EXISTS (
      SELECT 1 FROM song_versions sv
      WHERE sv.song_id = ${songs.id} AND sv.pipeline_status = 'idle'
    )`)
    .orderBy(asc(songs.popularity_rank))
    .limit(limit);
}
```

**`userSongProgress` schema reality** (schema.ts lines 529–568):
- Filter column: `completion_pct` real (0.0–1.0) per CONTEXT D-01.
- Order: `updated_at DESC` (timestamptz, not null).
- JOIN path: `userSongProgress.song_version_id` → `songVersions.id` → `songs.id`.

**Returned shape** (CONTEXT D-03): `{slug, title, artist, anime, youtube_id, jlpt_level, completion_pct, updated_at}` — mirrors `getFeaturedSongs` plus the two progress fields.

**SQL sketch from CONTEXT** (verify against drizzle in plan-phase):
```sql
SELECT s.slug, s.title, s.artist, s.anime, s.jlpt_level,
       (SELECT youtube_id FROM song_versions sv WHERE sv.song_id = s.id AND sv.youtube_id IS NOT NULL
        ORDER BY CASE sv.version_type WHEN 'tv' THEN 0 ELSE 1 END LIMIT 1) AS youtube_id,
       usp.completion_pct, usp.updated_at
FROM user_song_progress usp
JOIN song_versions sv ON sv.id = usp.song_version_id
JOIN songs s ON s.id = sv.song_id
WHERE usp.user_id = $1 AND usp.completion_pct > 0
  AND s.language = 'ja' AND s.quality_status = 'active'
ORDER BY usp.updated_at DESC
LIMIT $2
```
