## 5 Integration Test Cases

1. **Test 1 (unauth):** `getHeroSong(null)` returns `source='unauth_featured'`, `ctaLabel='Try Free Lesson'`, `ctaHref` matches `/songs/[slug]`, no `console.warn`.
2. **Test 2 (auth + resolvable slug):** Seeds `users.current_path_node_slug` to a real active ja song with lesson; expects `source='current_path'`, `ctaLabel='Resume Lesson'`, no warn.
3. **Test 3 (auth + null slug):** Seeds `current_path_node_slug=NULL`; expects `source='fallback_featured'`, `ctaLabel='Start Learning'`, NO warn (first-visit state per D-06).
4. **Test 4 (auth + drifted slug):** Seeds `current_path_node_slug='definitely-not-a-real-slug'`; expects `source='fallback_featured'`, `ctaLabel='Start Learning'`, exactly 1 warn matching `[hero-song] definitely-not-a-real-slug (current_path_node_slug) missing or lessonless`.
5. **Test 5 (verseCount JSONB):** `getHeroSong(null)` returns `song.verse_count` as a `number`; asserts `>= 0` (COALESCE guarantees number type even if lesson is NULL).

## Drizzle Quirks Discovered

- **`sql.raw('"songs"."id"')`** is required for correlated subqueries inside `db.select({})` — the `outerSongsId` pattern mirrors `starter-songs.ts`. Using `songs.id` directly inside the subquery causes Drizzle to render an unqualified column reference that resolves to the inner FROM, not the outer.
- **COALESCE wrapper for JSONB subquery** — `jsonb_array_length` returns NULL if no matching song_version row exists (song has no lesson). COALESCE(..., 0) ensures `verse_count` is always a number in the TypeScript return type.
- **Test DB skip guard** — `describeIfTestDb = HAS_TEST_DB ? describe : describe.skip` correctly skips all 5 tests when `TEST_DATABASE_URL` is absent. Tests report as "5 skipped" in CI environments without a test DB.
- **users table seeding for Test 2/3/4** — `getUserGamificationState()` uses `INSERT ... ON CONFLICT DO NOTHING` to auto-create a users row, then reads it. Tests seed `current_path_node_slug` via direct `INSERT ... ON CONFLICT DO UPDATE` before calling `getHeroSong()`.
