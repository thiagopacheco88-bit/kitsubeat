## Gap Closure: 14.2-12 Streak aria-label (MEDIUM gap)

Per orchestrator note and Plan 14.2-12 SUMMARY assertion-loss table:

The `threads streakCurrent into LanternStreak aria-label` assertion from `PathHeader.test.tsx` was not carried by any e2e spec. This plan adds it in `global-header-cross-surface.spec.ts`:

```typescript
const lanternStreakEl = page.locator(
  '[data-testid="global-lantern-streak"] [data-testid="lantern-streak"]',
);
const ariaLabel = await lanternStreakEl.getAttribute("aria-label");
expect(ariaLabel).toMatch(/^\d+-day streak$/);
```

This asserts the `<LanternStreak count={state.streak_current} />` component correctly threads the streak count into `aria-label="${count}-day streak"` at the global layout level (not just the old PathHeader context). Gap is now CLOSED.
