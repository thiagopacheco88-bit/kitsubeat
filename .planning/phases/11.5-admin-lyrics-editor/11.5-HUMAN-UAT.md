- **Path forward:** Add `vocab_item_id: string | null` to `Token` type and populate it in the lesson generation pipeline. Once landed, the existing `vocabMap` hook in page.tsx (lines 180-183) and the `TokenWithVocab` extended type in VerseRow are ready to activate without further admin-editor changes.
