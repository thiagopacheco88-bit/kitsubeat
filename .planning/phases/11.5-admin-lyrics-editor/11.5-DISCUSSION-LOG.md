## Area 3: Versioning + drafts schema

### Q3.1: lyrics_versions row shape

| Option | Description | Selected |
|--------|-------------|----------|
| Full snapshot in one jsonb (verses only) | id/song_version_id/version_number/source/editor_id/verses jsonb/parent/created_at | ✓ |
| Full lesson snapshot (verses + grammar + vocab) | Larger rows ~5–15KB | |
| Normalized: row per verse per version | Smaller blobs, complicates publish + gap analysis | |

**User's choice:** Full snapshot in one jsonb (recommended).
**Notes:** Locked in CONTEXT D-14. Verses-only chosen because grammar/vocab don't need per-version snapshotting.

### Q3.2: Active version pointer

| Option | Description | Selected |
|--------|-------------|----------|
| Pointer column on song_versions | `active_lyrics_version_id` FK | ✓ |
| is_active boolean on lyrics_versions | Partial unique index needed | |
| Latest version_number wins (no flag) | Doesn't support hide-during-rerun | |

**User's choice:** Pointer column on song_versions (recommended).
**Notes:** Locked in CONTEXT D-15. Two-write publish: pointer + lesson blob in same transaction.

### Q3.3: lyrics_drafts shape

| Option | Description | Selected |
|--------|-------------|----------|
| Single row per (song_version_id, editor_id) | PK = composite, full snapshot, dirty_verse_numbers int[] | ✓ |
| Per-verse draft rows | Finer granularity, harder stale detection | |
| Single jsonb on song_versions | No new table, weak ergonomics | |

**User's choice:** Single row per (song_version_id, editor_id) (recommended).
**Notes:** Locked in CONTEXT D-16. localStorage mirrors same shape (D-17).

### Q3.4: Stale-publish detection

| Option | Description | Selected |
|--------|-------------|----------|
| Compare base_version_id to current active | Optimistic concurrency, returns 409 | ✓ |
| Editor heartbeat + lock | Pessimistic, more state | |
| Compare verses snapshot hash | Same idea, hash-based | |

**User's choice:** Compare base_version_id to current active (recommended).
**Notes:** Locked in CONTEXT D-18.
