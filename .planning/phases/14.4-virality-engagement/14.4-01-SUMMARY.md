## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Playwright test.todo() is not type-safe in Playwright 1.59.1**
- **Found during:** Task 2 verification (tsc --noEmit)
- **Issue:** The plan specified `test.todo("description")` for E2E stubs, but `test.todo` does not exist on Playwright's `TestType` in v1.59.1. TypeScript reported TS2339 for all 5 E2E spec files.
- **Fix:** Replaced `test.todo("description")` with `test.fixme("description", async ({ page }) => { /* TODO */ })` which IS exported and type-safe in Playwright 1.x. All 5 E2E specs use `test.fixme` with async page fixture signature. Stubs still register as "skipped/fixme" in Playwright output.
- **Files modified:** tests/e2e/now-playing-chip.spec.ts, mastery-ticker.spec.ts, social-toggle-roundtrip.spec.ts, streak-saver-toast.spec.ts, cron-auth.spec.ts
- **Commit:** `a42f234`
