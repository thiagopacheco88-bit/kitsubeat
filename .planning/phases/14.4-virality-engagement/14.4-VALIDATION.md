## Sampling Rate

- **After every task commit:** Run `npm run test:unit`

- **Before `/gsd-verify-work`:** `npm run test:all` + `npm run lint` + `npm run build` (bundle delta) must all be green
- **Max feedback latency:** ~10 seconds (unit); ~60 seconds (integration)

## Security Threat Map

| Threat | STRIDE | Mitigation | Tested By |
|--------|--------|------------|-----------|
| Unauthenticated cron invocation | Spoofing | `assertCronSecret` → 401 on missing/mismatch | `cron/auth.test.ts` + `cron-auth.spec.ts` |
| Double-send from duplicate Vercel cron event | Tampering | `email_sent_log` composite PK prevents duplicate rows | `email-sent-log-idempotency.test.ts` |
| Social opt-in bypass in now-playing query | Tampering | SQL WHERE `social_activity_enabled = true` for auth users | `now-playing-counts.test.ts` |
| RESEND_API_KEY exposure in logs | Info Disclosure | Dry-run logs userId + subject only; key never logged | `send.test.ts` dry-run assertions |
| Email enumeration from cron logs | Info Disclosure | Log at `console.info` level only; no email addresses in stdout | Code review + copy review |
