## What Was Built

### AnimeCarouselExerciseSession.tsx
- Self-contained exercise session loop (no Zustand dependency)
- Renders one multiple-choice question at a time with progress bar and exit button
- On answer: highlights correct/incorrect, shows explanation, auto-advances after 1.5s
- Calls `recordVocabAnswer` fire-and-forget (only when `userId` truthy) with `songVersionId: null` and `cardKind: "romaji_meaning"`
- On last question: calls `saveAnimeCarouselSession` with collected answers, then calls `onComplete(result)`
- Graceful degradation: if save fails, synthesizes a local-count result and still calls `onComplete`

### AnimeSessionSummary.tsx
- Post-session results screen
- Shows emoji based on accuracy (>=80%: target, >=50%: books, else: muscle)
- Displays accuracy %, XP gained, day streak in a bordered stats row
- "Back to carousel" button calls `onBackToCarousel`

### AnimeVocabCarouselWrapper.tsx (replaced placeholder)
- 3-mode state machine: `"carousel"` | `"session"` | `"summary"`
- `carousel` mode: renders `AnimeVocabCarousel` with `onStartPractice` callback
- `session` mode: renders `AnimeCarouselExerciseSession` with all required props
- `summary` mode: renders `AnimeSessionSummary` (only when `sessionResult` is non-null)
- Back-to-carousel resets both `sessionQuestions` and `sessionResult`
