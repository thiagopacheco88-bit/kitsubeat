# Phase 18.3 Plan 06: AnimeIndexGrid Component Summary

**One-liner:** Client-side anime index grid with CardLink tiles, next/image cover art, JLPT badge, and word count overlay.

## What Was Built

`AnimeIndexGrid` is a `"use client"` React component that receives `AnimeCatalogEntry[]` and renders:

- A responsive 1/2/3-column grid using `CardLink` from the Card primitive
- Each card links to `/anime/{anime_slug}`
- Cover image using `next/image` with `fill` + `object-cover`, with a `🎌` emoji placeholder when `cover_image` is null
- Word count badge (Badge `variant="mono"`) overlaid on the cover image bottom-right
- Title (`title_english` with slug fallback via `SLUG_DISPLAY` map)
- JLPT badge (`variant="jlpt"`) when `top_jlpt` is present
- Two-line clamped description snippet
- Empty state ("No anime vocabulary available yet.") when `animes.length === 0`
