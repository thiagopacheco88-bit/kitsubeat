# Phase 18.3 Plan 02: Anime Vocab Seed Script Summary

Idempotent seed of 760 anime vocabulary words across 6 series using drizzle onConflictDoUpdate with JLPT-ranked display_order.

## What Was Built

Single seed script `scripts/seed/20-seed-anime-vocab.ts` that:
1. Reads 6 JSON files from `.planning/anime-vocab/` (one per anime series)
2. Upserts each word into `vocabulary_items` by `(dictionary_form, reading)` — updates `meaning` + `romaji` on conflict
3. Upserts each word into `anime_vocab_catalog` by `(anime_slug, vocab_item_id)` — updates `display_order` + `category` + `context_note` on conflict
4. Computes `display_order = jlptRank * 10000 + positionWithinLevel` (N5 first, anime-specific null terms last)

## Verification Results

- First run: 760 vocabulary_items upserted, 760 anime_vocab_catalog rows — exit 0
- Second run (idempotency): same counts, no errors, no duplicates — exit 0
- All 6 slugs processed: one-piece (109), naruto (128), bleach (133), fullmetal-alchemist (126), attack-on-titan (132), sword-art-online (132)

**3. [Rule 2 - Missing functionality] `onConflictDoUpdate` for anime_vocab_catalog**
