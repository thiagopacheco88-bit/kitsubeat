# Phase 18.3 Plan 05: Anime Vocab Carousel UI Components Summary

Four client-side React components for the anime vocab carousel: mastery-aware VocabWordCard, JLPT chip filter bar, category tab bar, and orchestrating AnimeVocabCarousel with client-side filtering and Practice CTA.

## What Was Built

### VocabWordCard (`src/app/anime/components/VocabWordCard.tsx`)
- Renders surface (kanji, 2xl bold), reading (hiragana), romaji, localized meaning
- MasteryDot component: grey (state=0 new), yellow (state=1 learning), green (state=2/3 mastered/relearning)
- JLPT badge via `<Badge variant="jlpt" level={...}>` with `isJlptLevel()` type guard; falls back to "Anime" mono badge for null levels
- Category chip via `<Badge variant="mono">`
- Optional context_note in italic italicised footer

### JlptFilterBar (`src/app/anime/components/JlptFilterBar.tsx`)
- Chips: All / N5 / N4 / N3 / N2 / N1 / Anime-specific
- `aria-pressed` on each button; active chip gets accent fill
- Exports `JlptFilter` type for use by AnimeVocabCarousel

### CategoryTabBar (`src/app/anime/components/CategoryTabBar.tsx`)
- Receives `categories: string[]` derived dynamically from word set
- Renders "All" + each category; `aria-selected` on active tab
- Returns null if categories is empty

### AnimeVocabCarousel (`src/app/anime/components/AnimeVocabCarousel.tsx`)
- Client island; accepts `words: AnimeVocabItem[]`, `animeMeta`, `locale`, optional `onStartPractice`
- `jlptFilter` + `categoryFilter` state; `filteredWords` via useMemo
- Renders word count ("N of M words shown") when animeMeta is present
- "Practice these words" button calls `buildAnimeCarouselQuestions(filteredWords, locale, 20)`; hidden when `onStartPractice` not provided
- 1/2/3-column grid of VocabWordCards; empty-state message when no matches
