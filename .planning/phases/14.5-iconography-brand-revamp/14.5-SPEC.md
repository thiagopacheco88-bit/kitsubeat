# Phase 14.5: Iconography & Brand Revamp — Specification

**Created:** 2026-05-08
**Ambiguity score:** 0.13 (gate: ≤ 0.20)
**Requirements:** 8 locked

## Goal

Replace KitsuBeat's raster brand chrome (5 files) and TierDivider inline SVG paths with a unified, visually consistent iconographic set — generated via ComfyUI or Gemini using locked prompts captured in `docs/icon-generation/` — while leaving the Phase 14.1 fox-mark wordmark and LanternStreak untouched.

## Background

`public/` contains `favicon.ico`, `apple-touch-icon.png`, `logo.png`, `logo-horizontal.png`, `logo-vertical.png`, `og-image.png` — all placeholder or generic assets. No `twitter-image.png` exists. `layout.tsx` wires `/favicon.ico`, `/apple-touch-icon.png`, and `/og-image.png` via Next.js metadata but has no `metadata.twitter` entry.

The nav logo is an inline SVG fox-face (ellipse + polygon ears + colored nose) in `layout.tsx:104-116` — this is the locked fox-mark from Phase 14.1 and is **not** touched by this phase.

`TierDivider.tsx` contains three hand-authored inline SVG paths (bamboo/torii/mountain) with `stroke="currentColor"` that were ported from a demo HTML file. They are functional but not visually polished.

There is no `docs/icon-generation/` directory. The ComfyUI pipeline is already wired for Phase 11.6 kanji mnemonic images (zero API cost). Gemini image generation is also acceptable as an alternative tool.

Cosmetic badge icons (`badge_scholar_fox` currently renders emoji `📚`) are **deferred** — the emoji placeholder is functional and sufficient for the current scope.

## Requirements

1. **logo.png regenerated**: A 512×512px raster brand mark that reads as a fox / anime music identity.
   - Current: `public/logo.png` exists but is a generic placeholder
   - Target: `public/logo.png` — 512×512px PNG, transparent background, fox/kitsune motif consistent with the app's anime-music identity; generated via ComfyUI or Gemini using the prompt captured in `docs/icon-generation/brand-prompts.md`
   - Acceptance: File exists at `public/logo.png`; dimensions are exactly 512×512px; background is transparent; visual passes manual review against the brand brief in `docs/icon-generation/brand-prompts.md`

2. **favicon.ico regenerated**: Multi-size favicon derived from the new logo art.
   - Current: `public/favicon.ico` exists but is a generic placeholder
   - Target: `public/favicon.ico` — ICO file containing 16×16 and 32×32 sizes; derived from the same logo art as req #1
   - Acceptance: `file public/favicon.ico` confirms ICO format; browser tab displays the new mark (manual smoke test)

3. **apple-touch-icon.png regenerated**: 180×180px touch icon for iOS.
   - Current: `public/apple-touch-icon.png` exists but is a generic placeholder
   - Target: `public/apple-touch-icon.png` — 180×180px PNG, no transparency (iOS crops to rounded rect with opaque bg), fox/kitsune motif on a solid dark background consistent with the app's dark theme
   - Acceptance: File exists at `public/apple-touch-icon.png`; dimensions are exactly 180×180px; background is opaque

4. **og-image.png regenerated**: 1200×630px Open Graph share card.
   - Current: `public/og-image.png` exists but is a generic placeholder
   - Target: `public/og-image.png` — 1200×630px PNG; includes "KitsuBeat" wordmark text and tagline "Learn Japanese through anime songs"; fox/kitsune visual motif; generated per prompt in `docs/icon-generation/brand-prompts.md`
   - Acceptance: File exists at `public/og-image.png`; dimensions are exactly 1200×630px; "KitsuBeat" text is legible at 1200×630px

5. **twitter-image.png added**: 1200×630px Twitter/X card image.
   - Current: No `public/twitter-image.png` exists; no `metadata.twitter` in `layout.tsx`
   - Target: `public/twitter-image.png` — 1200×630px PNG; may share the same source image as og-image.png or be a cropped variant
   - Acceptance: File exists at `public/twitter-image.png`; dimensions are exactly 1200×630px

6. **layout.tsx metadata updated**: `metadata.twitter` wired in `layout.tsx`.
   - Current: `layout.tsx:17-29` has `metadata.icons` and `metadata.openGraph.images` but no `metadata.twitter` block
   - Target: `layout.tsx` exports `metadata` with `twitter: { card: 'summary_large_image', title: 'KitsuBeat', description: 'Learn Japanese through anime songs', images: ['/twitter-image.png'] }`
   - Acceptance: `metadata.twitter.card` equals `'summary_large_image'`; `metadata.twitter.images` includes `'/twitter-image.png'`; TypeScript compiles without error

7. **TierDivider SVG paths redrawn**: Bamboo, torii, and mountain inline SVGs in `TierDivider.tsx` replaced with visually polished paths.
   - Current: `TierDivider.tsx:64-138` has three inline SVGs ported from a demo HTML file — functional but rough; all use `stroke="currentColor" fill="none"` viewBox 0 0 24 24
   - Target: Three redesigned SVG path sets in `TierDivider.tsx` — same `currentColor` / `aria-hidden` / `data-testid` contract; viewBox unchanged at `0 0 24 24`; visual quality improved to match Phase 14.1 polish level
   - Acceptance: All three `data-testid` attributes (`tier-icon-bamboo`, `tier-icon-torii`, `tier-icon-mountain`) still present; existing Vitest suite in `TierDivider.test.tsx` passes without modification; visual renders in both light and dark theme (manual check)

8. **Generation prompts committed**: `docs/icon-generation/brand-prompts.md` captures all prompts, negative prompts, and generation parameters used.
   - Current: No `docs/icon-generation/` directory exists
   - Target: `docs/icon-generation/brand-prompts.md` contains: tool used (ComfyUI model name or Gemini), prompt text per asset, negative prompt (if any), seed/parameters for reproducibility
   - Acceptance: File exists at `docs/icon-generation/brand-prompts.md`; contains entries for all 5 brand raster assets; could be used to regenerate the assets without guessing

## Boundaries

**In scope:**
- `public/logo.png` — new 512×512px fox/kitsune raster art
- `public/favicon.ico` — multi-size ICO (16×16, 32×32) from same art
- `public/apple-touch-icon.png` — 180×180px opaque iOS touch icon
- `public/og-image.png` — 1200×630px OG share card with wordmark + tagline
- `public/twitter-image.png` — 1200×630px Twitter card image (new file)
- `src/app/layout.tsx` — add `metadata.twitter` block only (no other layout changes)
- `src/app/path/components/TierDivider.tsx` — redesign the 3 inline SVG path sets only (no API changes, no prop changes, no test changes)
- `docs/icon-generation/brand-prompts.md` — generation prompts and parameters

**Out of scope:**
- The inline fox-face SVG in `layout.tsx:104-116` — this is the locked fox-mark from Phase 14.1; do not modify
- `<LanternStreak>` component — explicitly excluded per Phase 14.1 lock
- Cosmetic badge icons (`badge_scholar_fox`, etc.) — emoji fallback is functional; deferred
- `public/logo-horizontal.png`, `public/logo-vertical.png` — existing files; not required to update (may leave as-is)
- `TierDivider.tsx` component API, props, or tests — only SVG path bodies change; no structural changes
- Any changes to `/path` page beyond `TierDivider.tsx` SVG paths
- ComfyUI pipeline code changes — use existing wired pipeline from Phase 11.6 as-is
- Performance budgets / bundle size analysis — Phase 14.1 already established baselines

## Constraints

- All raster assets must be shipped at the dimensions specified: logo 512×512, favicon 16/32, apple-touch 180×180, og/twitter 1200×630
- `apple-touch-icon.png` must have an opaque background (iOS does not support transparent touch icons)
- SVGs in `TierDivider.tsx` must continue to use `stroke="currentColor"` with no raw hex values — must work in both dark and light themes
- `data-testid` attributes in `TierDivider.tsx` (`tier-icon-bamboo`, `tier-icon-torii`, `tier-icon-mountain`) must not change
- `docs/icon-generation/brand-prompts.md` must include enough detail that the assets can be regenerated without the author present (seed, model, prompt, negative prompt)
- No external API spend — ComfyUI (local) or Gemini (user-run) only
- No new npm dependencies — this phase does not add packages
