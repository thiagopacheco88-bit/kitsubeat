<decisions>
## Implementation Decisions

### Execution Workflow (D-01)

- **D-01 — Two-wave execution with explicit checkpoint.** Wave 1 is fully Claude-executable with no external tool dependency: TierDivider SVG redraw, `metadata.twitter` in `layout.tsx`, and complete `docs/icon-generation/brand-prompts.md`. Wave 2 requires user to run image generation (ComfyUI or Gemini) and place output files in `public/` — plan includes an explicit checkpoint task that pauses execution until raster assets land. Claude then handles dimension verification and `favicon.ico` synthesis (using `sharp` or equivalent — no new npm dep; use existing `sharp` if present, or instruct user on manual ICO generation via online tool / imagemagick if not). No API spend at any point.

- **D-02 — Tool-agnostic prompts.** `brand-prompts.md` contains prompts formatted for both ComfyUI (positive/negative prompt + model + seed) and Gemini (`google/gemini-2.0-flash` or similar). User picks whichever they have available. ComfyUI is preferred (already wired from Phase 11.6) but Gemini is the fallback if ComfyUI is unavailable.

### Visual Style Brief (D-03–D-06)

- **D-03 — Brand mark aesthetic: dark atmospheric anime-style fox portrait.** All 5 raster assets share a unified visual language:
  - Subject: stylized kitsune fox face/portrait (not full-body character) — close-up, anime-inspired, expressive
  - Background: very dark (#0a0a0a or near-black charcoal), matching the app's dark-first identity
  - Accent palette: orange/amber glow tones consistent with `--color-accent` (the fox-mark in nav uses `--color-grammar-adverb` which is a warm orange; raster art should echo this warmth)
  - Style: semi-illustrated (not photorealistic, not fully cel-shaded) — think anime character card aesthetic at high resolution
  - Music tie-in: subtle — a small musical note or audio waveform element in the composition, not the focal point

- **D-04 — `apple-touch-icon.png` opaque background.** Solid dark background (matching app dark theme, e.g. #0a0a0a or #111111). iOS crops to rounded rect — no transparency. Same fox portrait motif, cropped/centered for the 180×180 square.

- **D-05 — OG and Twitter share card composition.** Dark full-bleed background (#0a0a0a). Fox illustration (consistent with logo.png style) positioned left-of-center. "KitsuBeat" wordmark large (white/near-white) to the right. Tagline "Learn Japanese through anime songs" below the wordmark in a muted color. Both OG (1200×630) and Twitter (1200×630) use the same source image — no separate crop variant needed (SPEC allows this: req 5 says "may share the same source image").

- **D-06 — Logo.png transparent background.** 512×512px, transparent background (for flexible placement in any UI surface). The fox portrait motif renders against transparency — not a card/frame. The opaque dark background in other assets is applied at the asset level, not the logo.

### TierDivider SVG Redesign (D-07–D-09)

- **D-07 — Full clean redraw by Claude, same symbolic choices.** Not micro-edits to existing paths. Fresh path authoring for each of the three icons within the existing 24×24 viewBox. Preserve current `data-testid` attributes, `stroke="currentColor"`, `fill="none"`, `aria-hidden="true"` — no structural changes to the component.

- **D-08 — Target aesthetic: Heroicons/Lucide quality level.** 2px stroke width as baseline (current uses 1.4–1.8 — consolidate to 1.8 or 2 uniformly), `strokeLinecap="round"`, `strokeLinejoin="round"` throughout. Clean geometric paths, not rough approximations. Specifically:
  - **Bamboo**: Two parallel vertical stalks, evenly spaced, with clean horizontal node bands at regular intervals (not ellipses — use `rect` or `line` for node bands to look more graphic)
  - **Torii**: Architecturally correct proportions — gently curved kasagi top crossbeam (path with curve), lower shimaki, two vertical hashira, nuki tie-beam. More refined than the current flat lines.
  - **Mountain**: Clean ridgeline forming a classic mountain silhouette (two peaks — one tall, one shorter), snow-cap as a short `path` at the apex. Less complex than current multi-peak version — simpler reads better at 16px rendered size.

- **D-09 — No fill fills; all `currentColor`.** The existing bamboo ellipses use `fill="currentColor" opacity="0.55"` — this is acceptable. New paths may also use `fill="currentColor"` with opacity for depth/detail if desired, but primary strokes must be `stroke="currentColor"`.

### Metadata Wiring (D-10)

- **D-10 — `metadata.twitter` exact shape per SPEC.** `layout.tsx` exports `metadata` with: `twitter: { card: 'summary_large_image', title: 'KitsuBeat', description: 'Learn Japanese through anime songs', images: ['/twitter-image.png'] }`. No other changes to layout.tsx. TypeScript must compile clean.

### Claude's Discretion

- **Image processing tooling for favicon.ico**: If `sharp` is available as a transitive dep (likely — it's in Next.js), Claude can write a one-off script to synthesize the ICO from logo.png. If not, brand-prompts.md should include instructions for the user to generate favicon.ico manually (e.g., using favicon.io or imagemagick). Planner decides based on dependency audit.
- **Exact stroke weights and path coordinates** for the TierDivider redesign — Claude authors these to achieve the quality target without user review of every coordinate.
- **Whether to use `rect` vs `line` vs `path` for bamboo node bands** — whichever renders more crisply at 16px.
