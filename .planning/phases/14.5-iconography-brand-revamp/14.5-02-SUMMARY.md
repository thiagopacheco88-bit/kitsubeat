## Files Created

- `scripts/brand/verify-brand-assets.ts` — Sharp-based dimension + format validator. EXPECTED spec table with `allowAlpha: false` for apple-touch-icon. ICO magic bytes check via `readUInt32LE(0) === 0x00010000`. Exit code behavior: 0 = all pass, 1 = any failure.
- `scripts/brand/synthesize-favicon.ts` — ICO binary builder. 512×512 guard (throws on placeholder). Constructs ICO via `ico.writeUInt16LE`, `ico.writeUInt8`, `ico.writeUInt32LE` at exact byte offsets. `ico.writeUInt32LE(offset32, 34)` writes second directory entry fileOffset. Does NOT call `.ico()` (sharp 0.34.5 has no such method).

## Decisions Made

- Scripts committed even though verification runs fail — per checkpoint_override, user places assets later.
- The 512×512 guard in synthesize-favicon.ts is a correctness requirement (Pitfall 6 from RESEARCH.md): without it, favicon would be synthesized from 616×625 wrong-content placeholder art.
- `allowAlpha: false` for apple-touch-icon uses `console.error` (not `console.warn`) — per PLAN.md spec, this is a hard failure not a warning.
