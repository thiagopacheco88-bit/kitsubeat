<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CSS file loaded by Tailwind | `globals.css` is build-time + browser-runtime; no user input flows into the file |
| `data-theme` attribute on `<html>` | Set by SSR or inline script (covered in Plan 14-03 threat model); CSS only READS it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01-01 | Tampering | CSS variable injection via attribute selector | accept | `[data-theme="light"]` is a literal selector; only matches when the attribute equals `"light"`. Setting any other value (e.g., `"<script>"`) does NOT match, falling back to dark default. No XSS surface in CSS — `var()` cannot execute code |
| T-14-01-02 | Denial of Service | Reduced-motion override breaking critical UI | accept | The override only collapses durations to 0ms; end-state of every animation is the `100%` keyframe (which is the rest state). Worst case: instant transitions instead of smooth ones. Verified manually post-merge by toggling devtools "Emulate prefers-reduced-motion: reduce" |

Threats explicitly out of scope for Plan 14-01:
- Theme cookie tampering (covered in Plan 14-03)
- ESLint enforcement of token-only consumers (handled by Plan 14-00 Task 2's lint rule)
</threat_model>
