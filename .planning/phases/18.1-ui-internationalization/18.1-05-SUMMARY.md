## What Was Built

### src/app/[locale]/page.tsx — Locale Home Page

Mirrors `src/app/page.tsx` exactly with `setRequestLocale(locale)` as first call. English stays at `/` (root, `localePrefix: 'as-needed'`). `/pt-BR` and `/es` resolve here. Contains full home page structure (HeroFeatured, ContinueLearning, carousels, etc.) — same data fetching as EN root.

### src/app/[locale]/songs/page.tsx — Translated Songs Page

`setRequestLocale(locale)` + `getTranslations('songs')`. Page heading renders `t('heading')` ("Songs" / "Músicas" / "Canciones") and subheading `t('subheading')`. `SongGridLoader` is reused unchanged — it already handles language filter chips with `useTranslations('songs')` (Plan 04). English stays at `/songs` (unchanged).

### src/app/[locale]/journal/page.tsx — D-12 Locale-Ordered Journal Listing

`setRequestLocale(locale)` + `getTranslations('journal')`. Implements D-12:
- `localeArticles = getArticlesByLocale(locale)` — rendered first, no badge (primary content)
- `enArticles = getArticlesByLocale('en')` — rendered below with `<LanguageBadge locale="en" />`
- When locale articles exist, a horizontal divider with LanguageBadge separates sections
- EN articles also get LanguageBadge overlay on top-right of each card when in mixed view
- Empty state fallback if both arrays empty

### src/app/[locale]/journal/[slug]/page.tsx — Locale Article with EN Fallback

New file only — `src/app/journal/[slug]/page.tsx` (EN canonical) UNTOUCHED. Uses `getArticleSourceByLocale(slug, locale)` which reads locale MDX and falls back to EN automatically. `generateStaticParams()` enumerates all 3 locales × all article slugs. Canonical URL in `generateMetadata` always points to `/journal/slug` (EN root, D-02). `inLanguage` in JSON-LD reflects actual locale served. T-18.1-14 mitigated: SAFE_SLUG_RE guard is inside `getArticleSourceByLocale`.

### src/app/[locale]/profile/page.tsx — Translated Profile/Settings Page

`setRequestLocale(locale)` + `getTranslations('settings')`. Heading uses `t('heading')`. D-04 language preference row uses `t('language.label')` and `t('language.description')` with an inline `LanguagePicker` as secondary language selector (nav LanguagePicker is primary). Account section uses `t('account.heading')` and `t('data.export')`.

### src/app/[locale]/layout.tsx — LanguagePicker in Desktop Nav

Added `import { LanguagePicker } from "@/components/ui/LanguagePicker"` and `<LanguagePicker currentLocale={locale as "en" | "pt-BR" | "es"} />` immediately after `<ThemeToggle userId={signedInUserId} />` in the nav. Globe icon now visible in desktop header on all `/pt-BR/*` and `/es/*` routes.

### src/app/sitemap.ts — hreflang Alternates for All Entry Types

Added `alternates.languages` using `MetadataRoute.Sitemap`'s native field (no type casting required). Coverage:
- Static pages (home, /songs, /anime-list, /journal): pt-BR and es alternates
- Dynamic song entries: `/pt-BR/songs/{slug}` and `/es/songs/{slug}`
- Dynamic article entries: `/pt-BR/journal/{slug}` and `/es/journal/{slug}`

### src/app/sitemap.test.ts — New Assertions

Added 3 new test cases: homepage alternates.languages, article alternates.languages, song alternates.languages. All 8 sitemap tests pass.
