## Interaction Contracts

### Globe Icon Button (Nav)
- Position: right side of nav, between `<ThemeToggle>` and `<UserButton>` — immediately left of ThemeToggle
- Trigger: click/tap opens a dropdown panel (not a modal)
- Icon: inline SVG globe, 18×18px, `text-[var(--color-text-muted)]`
- Button: ghost variant — `min-h-[44px] min-w-[44px]`, `rounded-[var(--radius-md)]`, `hover:bg-[var(--color-card-2)]`
- aria-label: `"Change language"` (English), also needs `aria-expanded` and `aria-haspopup="listbox"`
- Active locale indicator: show current locale code ("EN", "PT", "ES") in `text-xs font-semibold text-[var(--color-text-muted)]` beside the globe (hidden on mobile, shown on sm+)

### Language Dropdown Panel
- Width: `min-w-[160px]`, right-aligned to the button
- Background: `bg-[var(--color-card)] border border-[var(--color-border)] rounded-[var(--radius-xl)] shadow-[var(--shadow-card-ring-strong)]`
- Options: 3 rows — "English", "Português-BR", "Español"
- Each option: `min-h-[44px] px-4 flex items-center text-sm text-[var(--color-text-muted)]`
- Selected option: `text-[var(--color-text)] font-semibold` + inline check mark (inline SVG, 14×14px, `text-[var(--color-accent)]`) on the right
- Hover: `hover:bg-[var(--color-card-2)] hover:text-[var(--color-text)]`
- Close: click outside, Escape key, or selecting an option
- Implementation: use `@radix-ui/react-dialog` (already installed) or a custom Popover built on `useEffect` + `useRef` — no new deps
- Transition: `transition-opacity duration-[120ms]` on open/close — matches `--duration-fast`

### Language Filter Chip (Songs Page)
- Position: alongside existing JLPT and difficulty chip rows in `SongGrid.tsx`
- Options: "JA", "EN", "PT", "ES" (matches DB `language` column values)
- Default: no language filter active (shows all songs)
- Chip style: identical to existing JLPT/difficulty chips
  - Inactive: `bg-[var(--color-card-2)] text-[var(--color-text-muted)] min-h-11 rounded-[var(--radius-md)] px-3 text-xs font-semibold`
  - Active: `bg-[var(--color-text)] text-[var(--color-bg)] min-h-11 rounded-[var(--radius-md)] px-3 text-xs font-semibold`
- "Clear" button behavior: clears language filter alongside existing JLPT/difficulty clears

### Journal Article Language Badge (EN marker)
- Position: top-right corner of JournalCard for English articles when user locale is PT-BR or ES
- Style: `inline-flex items-center rounded-full bg-[var(--color-card-2)] border border-[var(--color-border)] px-2 py-0.5 text-xs font-semibold text-[var(--color-text-muted)]`
- Label: `"EN"` — the 2-character ISO code only, no flag emoji, no full word
- PT-BR/ES articles appear first in the list with no badge; EN articles appear below with the EN badge
- No tab navigation or separate sections needed (D-12: ordering only, not tabbed)

### Locale Preference Persistence (Visual Only)
- No visible spinner or loading state on locale switch — the redirect is instant
- On cookie write + redirect: use Next.js router navigation (no skeleton needed, normal page load)
- If locale preference fails to save to Clerk metadata (e.g. network error): fail silently — cookie drives routing, Clerk sync is a background enhancement

## Accessibility Contract

- Globe button: `aria-label="Change language"`, `aria-expanded={isOpen}`, `aria-haspopup="listbox"`
- Dropdown: `role="listbox"`, `aria-label="Select language"`, focus trap on open
- Language options: `role="option"`, `aria-selected={isCurrentLocale}`
- Language filter chips: `aria-pressed={isActive}` on each chip button — matches existing JLPT chip pattern
- Journal EN badge: `aria-label="Article in English"` (descriptive, not just "EN")
- All locale-switched pages: `<html lang={locale}>` updated dynamically — this is the primary a11y win of the phase
- Focus ring: `focus-visible:ring-2 focus-visible:ring-[var(--color-accent)]/40` — matches existing Button primitive
