## What Was Built

### LanguagePicker (src/components/ui/LanguagePicker.tsx)

`"use client"` component — structural analog of ThemeToggle.tsx.

- **GlobeIcon** and **CheckIcon**: inline SVG functions (no lucide-react — project constraint)
- **LOCALE_OPTIONS**: `const` tuple of `[{ value, label, code }]` for `en`, `pt-BR`, `es`
- **Globe button**: ghost variant, `!min-h-[44px] !min-w-[44px] !p-2`, with `aria-expanded`, `aria-haspopup="listbox"`, `aria-label="Change language"`
- **Active locale indicator**: `{currentOption?.code}` beside globe, `hidden sm:block` (visible on desktop only — UI-SPEC)
- **Dropdown**: `role="listbox"`, right-aligned, `min-w-[160px]`, all color tokens using `var(--color-*)`
- **Options**: `role="option"`, `aria-selected`, selected option shows CheckIcon in `var(--color-accent)`
- **Locale switch**: `router.replace(pathname, { locale: newLocale })` from `@/i18n/navigation` — next-intl middleware writes `kb_locale` cookie automatically; no `document.cookie` write in component
- **Clerk sync**: `syncLocaleToClerk` called inside `startTransition` with try/catch silent — cookie is primary
- **Escape close**: `useEffect` + `document.addEventListener("keydown")`
- **Outside-click close**: `useRef<HTMLDivElement>` + `pointerdown` listener

### LanguageBadge (src/components/ui/LanguageBadge.tsx)

Server Component (no `"use client"` directive).

- Derives 2-char display code: `'en' → 'EN'`, `'pt-BR' → 'PT'`, `'es' → 'ES'`
- Derives full name for `aria-label`: `"Article in English"`, `"Article in Portuguese"`, `"Article in Spanish"`
- Style: `inline-flex items-center rounded-full bg-[var(--color-card-2)] border border-[var(--color-border)] px-2 py-0.5 text-xs font-semibold text-[var(--color-text-muted)]` — matches UI-SPEC exactly
- Defaults `locale` prop to `"en"` — safe for callers that don't pass it

### MobileNavSheet (src/app/components/MobileNavSheet.tsx) — Extended

- Added imports: `useLocale` from `next-intl`, `LanguagePicker` from `@/components/ui/LanguagePicker`
- Added `const locale = useLocale() as "en" | "pt-BR" | "es"` inside component (already `"use client"`)
- Added LanguagePicker render at foot of nav link list: `<div className="flex items-center px-1 pt-2 border-t border-[var(--color-border-strong)]"><LanguagePicker currentLocale={locale} /></div>`
- `useLocale()` works because `NextIntlClientProvider` is present in both root `layout.tsx` and `[locale]/layout.tsx` (Plan 02) — provider always in scope for all routes
