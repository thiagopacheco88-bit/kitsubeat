## Locale Routing

| Option | Description | Selected |
|--------|-------------|----------|
| URL prefix — /pt-BR/songs, /es/songs | next-intl default. Static page per locale. Best SEO, shareable URLs. | ✓ |
| Same URL, language from cookie/header | Simpler URL but worse SEO, language invisible in URL. | |
| Subdomain — pt.kitsubeat.com | Strongest SEO isolation but operational complexity. | |

**User's choice:** URL prefix routing
**Notes:** English stays at root `/` — no `/en/` prefix. Existing indexed URLs are not broken.

---

## Journal Strategy

| Option | Description | Selected |
|--------|-------------|----------|
| Show English articles in all locales with a badge | Zero translation work, hreflang canonicals prevent SEO penalty. | |
| Hide journal for PT-BR and ES | Neutral SEO, no duplicate content risk, loses engagement. | |
| Translate all 28 articles | Best SEO — unique content per locale. | ✓ |

**User's choice:** Translate all 28 articles
**Notes:** User asked about SEO implications before deciding. Claude explained hreflang canonicals handle Option 1 safely but Option 3 is the strongest SEO play. User also wants PT-BR/ES articles to appear first on the listing page, English below with EN badge. Translation method: Claude Code inline (no API cost). Journal UX: user's language first, others below (no filter tabs).
