## What Was Built

### src/lib/db/queries.ts — getAllSongs Extended

Changed signature from `getAllSongs(userId?)` to `getAllSongs(userId?, languageFilter?)`. Added `language: songs.language` to the SELECT clause (placed after `difficulty_tier`). Replaced the hardcoded `AND ${songs.language} = 'ja'` filter in the WHERE clause with a conditional: `${languageFilter ? sql\`AND ${songs.language} = ${languageFilter}\` : sql\`\`}`. This is a Drizzle parameterized query — no SQL injection risk (T-18.1-13 mitigated). The `SongListItem` type is automatically updated via `Awaited<ReturnType<typeof getAllSongs>>[number]`.

All 5 other query functions that contained `${songs.language} = 'ja'` were left untouched — those are intentional JA-only filters for carousel/home page queries.

SongGridLoader calls `getAllSongs(userId)` with no second arg — backward compatible, returns all active songs.

### src/app/songs/components/SongGrid.tsx — Language Filter Chips

Added `useTranslations` import from `next-intl` and `const t = useTranslations('songs')`. Added `LANGUAGE_OPTIONS` constant with `{ value: 'ja'|'en'|'pt'|'es', label: 'JA'|'EN'|'PT'|'ES' }` entries. Added `languageFilter` state alongside existing `jlptFilter`/`difficultyFilter`.

Updated `hasFilters` to include `languageFilter !== null`. Added language filter step to `useMemo` chain: `if (languageFilter) { result = result.filter((s) => s.language === languageFilter); }`. Added language chip row in JSX with identical token classes to existing JLPT/difficulty chips, and `aria-pressed={languageFilter === option.value}` for accessibility.

Updated Clear button onClick to also call `setLanguageFilter(null)`.

Added locale-translated language empty-state (D-07): shown when `languageFilter !== null && filtered.length === 0 && !search && !jlptFilter && !difficultyFilter` — uses `t('empty.noLanguage.heading')`, `t('empty.noLanguage.body')`, `t('empty.noLanguage.cta')` (never hardcoded EN strings). The existing generic EmptyState is now guarded to not show when the language empty-state is already shown.

### src/lib/journal/articles.ts — Locale Functions

Added `getArticlesByLocale(locale: 'en' | 'pt-BR' | 'es')`: reads from `CONTENT_DIR` for `'en'`, from `CONTENT_DIR/locale` for others. Returns `[]` if the locale subdir does not exist. Files are sorted by date descending (same as `getAllArticles`).

Added `getArticleSourceByLocale(slug, locale)`: applies `SAFE_SLUG_RE` guard first (T-18.1-11 mitigated — blocks `../admin`, uppercase slugs). Reads locale file; falls back to `getArticleSource(slug)` (EN) if locale file missing. Returns `null` for invalid slugs or missing EN files.
