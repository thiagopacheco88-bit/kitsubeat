- **After every task commit:** Run `npm run test:unit`
- **After every plan wave:** Run `npm run test:integration`
- **Before `/gsd-verify-work`:** `npm run test:all` must be green
- **Max feedback latency:** ~10 seconds (unit), ~60 seconds (integration)

## Manual-Only Verifications

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| Subject quality of curated 50 images (does the photo *match* the word?) | AC-8 | Cannot be programmatically asserted without a vision model — out of scope for this validation set. | After `19b-load-vocab-images.ts` runs, operator opens a debug HTML preview (or `/vocabulary` filtered to image-bearing rows) and eyeballs all 50 images. Reject any whose subject does not depict the target meaning; replace URL in the TSV and re-run loader. |
| LearnCard tap-to-dismiss preserved when image renders | AC-3 | Tap-to-dismiss is the LearnCard outer-div `onClick={onDismiss}` (line 49). Component test asserts `<img>` does not have its own click handler, but the actual interaction-with-card behavior under user input is best confirmed by hand. | In dev (`http://localhost:7000`), open a song with a curated vocab, trigger LearnCard JIT, verify a single tap anywhere on the image dismisses the card identically to tapping the meaning paragraph. |
| FeedbackPanel image visible only when "More" accordion is open | AC-4 | Accordion-open persistence is session-store state — easier to validate by hand than to mock the Zustand store across questions. | In dev, complete a question for an image-bearing vocab. Verify image is hidden until "More" is tapped, persists open across the next question, image stays visible. |
