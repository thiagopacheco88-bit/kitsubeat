## Decisions Made

- **D-01 honored:** `image_url` is nullable `text` on `vocabulary_items` — single column, full URL stored as-is. Matches the WORKLOG and `11.4-CONTEXT.md` lock.
- **D-02 honored:** migration numbered `0014_vocab_image_url.sql` (corrects WORKLOG draft `0009_vocab_image_url.sql`); 0009-0013 are already-shipped migrations.
- **D-03 honored:** Zod passthrough is `.string().url().optional()` only — NOT `.nullable()`. `image_url` has no semantic null state (absence = undefined), unlike `kanji_breakdown` which is nullable for kana-only words.
- **D-12 codified inline:** the `^https://images\.unsplash\.com/.+` URL regex is asserted directly in `tests/integration/seed-19b-load-vocab-images.test.ts`. Plan 11.4-03's loader will import or duplicate the same regex.
- **Migration hand-written, not generated:** `db:generate` would have bundled an unrelated `songs.popularity_rank` diff into 0014 (deferred D-01). Hand-writing 0014 following the `0004_vocab_enrichment.sql` precedent kept the migration scoped to `image_url` only — same approach used for the 07-01 manual-migration precedent recorded in STATE.md.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] Migration hand-written instead of db:generate output**
- **Found during:** Task 2 (`npm run db:generate`)
- **Issue:** `db:generate` interactively prompted to either CREATE `popularity_rank` on `songs` or RENAME one of several existing columns to `popularity_rank` — a pre-existing schema drift (see deferred D-01). Bundling that diff into Plan 11.4-01's migration would have polluted the scope and risked an unintended rename.
- **Fix:** Hand-wrote `drizzle/0014_vocab_image_url.sql` following the `drizzle/0004_vocab_enrichment.sql` precedent (single `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`). Same pattern used for 07-01's manual-migration precedent already recorded in STATE.md.
- **Files modified:** `drizzle/0014_vocab_image_url.sql` (created)
- **Verification:** Migration applied cleanly via `tsx scripts/apply-migrations.ts`; live DB column verified via `scripts/debug/verify-image-url-column.ts`.
- **Committed in:** `f469b4b`
