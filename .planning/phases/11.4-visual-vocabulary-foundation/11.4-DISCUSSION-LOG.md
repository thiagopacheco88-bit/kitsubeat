## Image dimensions & aspect ratio

| Option | Description | Selected |
|--------|-------------|----------|
| Square (1:1) | Universal aspect; matches Anki/WaniKani precedent; easiest to enforce via Unsplash crop URL params | ✓ |
| 16:9 landscape | Movie-poster aesthetic; biases toward wide subjects (landscapes/scenes) | |
| 4:3 | Compromise; reads as "photo" but no clear advantage over square | |
| Variable | Trust Unsplash native aspect | |

**Auto-selected:** Square (1:1) — recommended.
**Sub-decisions:**
- LearnCard size: ~220px centered max-width
- FeedbackPanel size: ~120px thumbnail
- Skeleton uses identical dimensions (fixed `width`/`height` HTML attrs, not just CSS) to prevent layout shift

**Notes:** Square framing is neutral for both noun (object) and verb (action) imagery, which matters because curation pulls from both POS classes. Anki Image Occlusion + WaniKani both use square-ish thumbnails for the same reason.

## Curation criteria — what counts as "concrete"

| Option | Description | Selected |
|--------|-------------|----------|
| Frequency-rank only (top 50 by appearance count) | Simplest; trusts frequency as proxy for value | |
| Frequency-rank + POS filter (nouns + concrete verbs only) | Excludes particles, expressions, adverbs, adjectives — highest "imageable" hit rate | ✓ |
| Hand-pick from a curated frequency list | Highest quality but slowest; over-engineered for 50-row validation | |

**Auto-selected:** Frequency-rank + POS filter (nouns + concrete verbs only) — recommended.
**Notes:** Adjectives may be revisited later (e.g. 赤い red is imageable) but excluded for the validation set to maximize hit rate. Adverbs/particles/expressions are inherently hard to depict.

## Failure handling — broken image URL

| Option | Description | Selected |
|--------|-------------|----------|
| Silent hide (onError → collapse) | Image is decorative; absence shouldn't break the surface | ✓ |
| Show placeholder/icon | Communicates "image was supposed to be here" but adds visual noise | |
| Fall through to skeleton permanently | Misleading — skeleton implies "still loading" | |

**Auto-selected:** Silent hide via `onError` handler — recommended.
**Notes:** Image is a memory aid, not load-bearing UI. Card/panel must remain fully usable when image fails or is absent. `console.warn` once per failed URL for future audit visibility.

## Curation script output format

| Option | Description | Selected |
|--------|-------------|----------|
| TSV staging file → operator fills `image_url` → loader applies | Mirrors `scripts/seed/11-enrich-vocab.ts` resume-from-staging pattern; resume-friendly | ✓ |
| Inline (per-word prompt during script run) | Slow for 50 rows; no resume | |
| JSON staging file with auto-validation | Pedantic; TSV is operator-friendlier for batch URL entry in a spreadsheet | |

**Auto-selected:** TSV staging file → operator fills → loader applies — recommended.
**Notes:** Two-step pattern. Staging columns: `vocab_item_id | dictionary_form | reading | meaning_en | suggested_query | image_url`. Re-runs idempotent. Operator can leave the curation half-done and resume.

## QA gate — validation strategy

| Option | Description | Selected |
|--------|-------------|----------|
| URL pattern regex at insert + operator eyeball pass | Pattern enforces CC0 license origin; subject quality stays human-judged | ✓ |
| Trust operator (no automated gate) | Risky — typo'd URLs would silently 404 in prod | |
| LLM vision-check (subject vs meaning) | Out of scope for 50-image validation; would belong in a v4.0 rollout gate | |

**Auto-selected:** URL pattern regex at insert + operator eyeball pass — recommended.
**Notes:** Pattern: `^https://images\.unsplash\.com/.+`. CC0 license enforcement is a function of the host. Operator runs a `--verify` re-pass to confirm all 50 target rows have a populated `image_url` and passes the regex.
