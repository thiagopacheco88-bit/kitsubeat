# Phase 18 — UI Design Contract

> Visual and interaction contract for legal compliance surfaces.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

This phase adds compliance-required surfaces on top of the existing Phase 14 design system.
It does NOT redesign any existing product surfaces. Every token reference is a pre-existing
CSS custom property from `src/app/globals.css`. No new tokens are introduced.

All values from existing `--space-*` tokens in `globals.css`. No exceptions for Phase 18.

| Token | Value | Phase 18 Usage |
|-------|-------|----------------|
| `--space-1` | 4px | Icon-to-text gap in AiBadge; inline consent link padding |
| `--space-2` | 8px | Button gap in consent banner; checkbox + label gap |
| `--space-3` | 12px | Consent banner internal padding (horizontal, mobile) |
| `--space-4` | 16px | Legal page section padding; form field spacing |
| `--space-5` | 20px | Consent banner internal padding (horizontal, desktop) |
| `--space-6` | 24px | Legal page paragraph top margin; profile nudge banner padding |
| `--space-7` | 32px | Legal page section breaks |
| `--space-8` | 40px | Legal page `py-10` equivalent |
| `--space-9` | 48px | Legal page top/bottom page padding |
| `--space-10` | 64px | Not used in Phase 18 |

**Touch targets:** All interactive elements (banner buttons, checkboxes, CTA buttons) must meet
44×44px minimum tap target per WCAG 2.5.5. Use `min-h-[44px]` on all `<button>` elements —
same contract as `Button.tsx` already enforces. Checkbox click area: wrap in `<label>` with
`py-2 px-1` to expand hit area to 44px height.

**Consent banner height:** Maximum 96px on desktop (2 lines of text + 2 buttons side by side).
On mobile (< 640px), stacks vertically — maximum 160px. Banner must not obscure more than 20%
of viewport height on any screen size.

## Color

All values from `src/app/globals.css`. No new color tokens.

| Role | Dark Value | Light Value | Usage |
|------|-----------|-------------|-------|
| Dominant (60%) | `--color-bg` (#0E0E0E) | `--color-bg` (#FAFAF9) | Page backgrounds; legal page surface |
| Secondary (30%) | `--color-card` (#191919) | `--color-card` (#FFFFFF) | Consent banner background; nudge banner |
| Accent (10%) | `--color-accent` (#dc2626) | `--color-accent` (#dc2626) | Accept CTA button only (consent banner) |
| Accent readable | `--color-accent-readable` (#ef4444 dark / #dc2626 light) | same | In-prose links on legal pages; "Complete your profile" nudge link |
| Destructive | `--color-accent` (#dc2626) | same | No destructive actions in Phase 18 (data export is not destructive; no delete flows) |
| Muted text | `--color-text-muted` | same | Consent banner body; legal page version line; nudge banner body |
| Dim text | `--color-text-dim` | same | AiBadge text (60% opacity applied via `opacity-60` class) |
| Border | `--color-border` | same | Consent banner top border; legal page inter-section dividers |
| Border strong | `--color-border-strong` | same | Focused input ring on age-gate form |

**Consent banner color contract (WCAG AA critical):**

The banner renders on `--color-card` background. Text contrast verified:
- `--color-text` on `--color-card` dark (#F5F5F4 on #191919): 13.8:1 — PASS AA + AAA
- `--color-text` on `--color-card` light (#18181B on #FFFFFF): 18.1:1 — PASS AA + AAA
- "Reject non-essential" button (secondary variant): `--color-text` on `--color-card-2` — PASS
- "Accept" button (primary variant): white on `--color-accent` (#dc2626): 4.66:1 — PASS AA

**AiBadge color contract:**
- Text: `--color-text-dim` at `opacity-60`
- Dark: rgba(245,245,244,0.40) × 0.60 ≈ 24% white on #191919 card — this is 10px decorative
  text, not functional content. Apply `aria-hidden="false"` and `aria-label` for screen readers
  so the contrast requirement is met via accessible name rather than visual contrast.
- Alternative: Use `--color-text-muted` (56% opacity) without additional `opacity-60` if
  axe-core flags the dim+opacity combination. axe-core run will determine final value.

**Accent is reserved for:**
- "Accept" (consent CTA) primary button background
- In-prose hyperlinks on legal pages (`--color-accent-readable`)
- "Complete your profile" link text in the nudge banner
- No other elements in Phase 18 use accent

## Surface Contracts

### Surface 1: Cookie Consent Banner

**Component:** `src/components/CookieConsentBanner.tsx` (new, client island)

**Layout:**
- Fixed to bottom of viewport: `fixed bottom-0 left-0 right-0 z-50`
- Background: `bg-[var(--color-card)]`
- Top border: `border-t border-[var(--color-border)]`
- Padding: `px-4 py-4 sm:px-6` (16px mobile, 24px desktop)
- Inner layout: flex row on desktop (text left, buttons right), stacked on mobile
- Max content width: `max-w-6xl mx-auto` (matches global nav container)
- Shadow: `shadow-[0_-4px_20px_rgba(0,0,0,0.15)]` on dark; `shadow-[0_-4px_20px_rgba(0,0,0,0.06)]` on light

**Anatomy:**
1. Body text (14px, `--color-text-muted`, `leading-[1.5]`): "We use cookies for essential functionality and, with your consent, analytics to improve KitsuBeat."
2. Cookie Policy link: inline `<a href="/legal/cookie-policy">` styled `--color-accent-readable`, underline
3. Button row: `flex gap-2 flex-shrink-0 mt-3 sm:mt-0`
   - "Reject non-essential" — `Button` variant=secondary size=sm
   - "Accept all cookies" — `Button` variant=primary size=sm

**Accessibility:**
- `role="dialog"` `aria-label="Cookie consent"` `aria-modal="false"` on root `<div>`
- `aria-live="polite"` on root div so screen readers announce on mount
- Focus: when banner mounts, focus moves to the "Reject non-essential" button (safer default)
- After choice: banner unmounts; focus returns to `<body>` (no specific target)
- Keyboard: Tab navigates Reject → Accept → Cookie Policy link; Escape does NOT dismiss (must make an explicit choice — PECR compliance)

**Flash/CLS prevention:**
- `RootLayout` reads `kb_consent` cookie via `cookies()` SSR and passes as `initialConsent` prop
- If `initialConsent` is set, `CookieConsentBanner` returns `null` immediately (SSR)
- No hydration flash — component starts hidden, never shown if cookie exists
