| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-15-10 | Information Disclosure | PostHog token in browser | accept | NEXT_PUBLIC_POSTHOG_TOKEN is intentionally browser-exposed (PostHog is designed for this); token is project-scoped and cannot access other projects' data |
| T-15-11 | Elevation of Privilege | Sentry auth token scopes | mitigate | Token scoped to project:releases + org:read only; no write access to production data |
</threat_model>
