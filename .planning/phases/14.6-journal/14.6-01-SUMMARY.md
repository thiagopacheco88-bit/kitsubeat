## Decisions Made
- Added `vi.mock('server-only', () => ({}))` to test file — the `server-only` package unconditionally throws when imported outside the Next.js RSC runtime, so vitest Node environment needs it mocked. This is the correct approach: the import 'server-only' guard remains in production and prevents accidental client bundling; tests bypass it since they are testing utility logic, not RSC compliance.
- Used `fs.existsSync(CONTENT_DIR)` guard at top of getAllArticles() — returns [] if the journal directory doesn't exist yet. This makes the Wave 2/3 pages safe to build even before any MDX files are dropped.
