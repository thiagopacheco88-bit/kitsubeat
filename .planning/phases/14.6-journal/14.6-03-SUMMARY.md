## Decisions Made

- `<` Unicode escape chosen over `&lt;` for JSON-LD XSS safety — `<` is valid JSON, safe in `<script>` context, and is the pattern shown in Next.js official JSON-LD docs
- OG image URL uses ternary: `coverImage.startsWith('/') ? BASE_URL + coverImage : coverImage` — handles both local public paths and external URLs without constraining Subutai's frontmatter format
- `compileMDX` is called twice per request (once in `generateMetadata`, once in the page function) — per RESEARCH.md Pitfall 1, this is acceptable at build time (SSG) and React.cache() optimization is deferred

## User Setup Required

**NEXT_PUBLIC_SITE_URL must be added to Vercel project environment variables.**

- Variable: `NEXT_PUBLIC_SITE_URL`
- Value: `https://kitsubeat.vercel.app`
- Location: Vercel Dashboard → kitsubeat project → Settings → Environment Variables
- Why: Canonical URLs and OG image URLs for all journal articles will use the hardcoded fallback (`https://kitsubeat.vercel.app`) if this var is not set — correct for production, but Vercel preview deployments will emit the wrong canonical URL without this env var set to the production domain.

Without this step: SEO canonical tags on Vercel preview deployments will point to `https://kitsubeat.vercel.app` (the fallback) rather than the preview URL — this is acceptable behavior since canonical should always point to the production domain anyway. But explicitly setting the env var is best practice.
