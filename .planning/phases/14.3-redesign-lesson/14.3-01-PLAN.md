# 14.3-01 PLAN: Lesson Shell And Gear Shift

## Intent

Create the foundation for Phase 14.3 by replacing the ad hoc lesson chrome with a music-player stage and an explicit Practice gear-shift action. Keep behavior additive: no data, scoring, player, or exercise generation changes.

## Files

- `src/app/songs/[slug]/components/SongContent.tsx`
- `src/app/songs/[slug]/components/SongLayout.tsx`
- `src/app/songs/[slug]/components/PlayerControls.tsx`
- `tests/e2e/mobile-parity.spec.ts`

## Tasks

1. Tokenize the song session header, version toggle, lesson copy, tab strip, and Suspense fallback in `SongContent.tsx`.
2. Add a prominent `Start practice` / `Back to practice` gear-shift button that switches the existing tab state to Practice.
3. Restyle `SongLayout.tsx` as a unified player stage with stable mobile dimensions and data test hooks.
4. Tokenize `PlayerControls.tsx` so the language/furigana controls no longer drive the lesson chrome with raw gray utilities.
5. Tighten the `/songs/again-yui` mobile horizontal-scroll assertion from the old deferred leniency toward strict no-overflow for the page.

## Verification

- `npx playwright test tests/e2e/mobile-parity.spec.ts -g "/songs/again-yui.*no horizontal scroll" --workers=1 --reporter=line`
- `npx vitest run src/app/songs/[slug]/components/__tests__`
- `npm run build`
