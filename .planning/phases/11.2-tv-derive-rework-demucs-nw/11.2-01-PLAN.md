<objective>
Build the TV-mode mirror of the full-version Demucs+WhisperX pipeline. Two new Python scripts that take a slug (or `--all`), download the TV YouTube cut, isolate vocals via htdemucs, and transcribe with WhisperX large-v3 ja — writing to TV-specific paths that the new NW derive script will consume.

Purpose: SPEC-REQ-1 mandates a TV equivalent of `ab-demucs-isolate.py` + `ab-transcribe-stems.py`. Today only the full-version scripts exist (hardcoded to `public/audio/`, `data/vocal-stems/`, `data/timing-cache-stem/`). One TV song (sign-flow) was processed by hand; this plan generalizes that to all 60.

Output: Two idempotent Python scripts. After this plan, anyone can run `python scripts/seed/tv-demucs-isolate.py --all` followed by `python scripts/seed/tv-transcribe-stems.py --all` and get clean stem-WhisperX timing JSON for every TV song.

EXTRACT_MODULE_PATH = "scripts/seed/04-extract-timing.py"

def load_extractor():

    spec.loader.exec_module(module)
