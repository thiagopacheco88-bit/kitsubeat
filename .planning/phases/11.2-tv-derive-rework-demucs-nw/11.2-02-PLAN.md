type NWResult = {

**Pipeline per slug:**

1. **Load full lesson:** `data/lessons-cache/{slug}.json` → parse as Lesson. (Mirror old 10b's loader.)

2. **Load TV-stem timing:** `data/timing-cache-tv-stem/{slug}.json` → parse to `{words: [{start, end, text}, ...]}`. Skip if missing (warn).

3. **Build full-lesson alignment stream:**
   - For each verse in lesson.verses:
     - For each token in verse.tokens: append `normRomaji(toHepburnRomaji(tokenAlignText(tok), kuroshiro))` to `streamA`.
     - At end of verse: append `VERSE_BOUNDARY_MARKER` to `streamA`. Record `verseRanges = [{verseNumber, charStart, charEnd}, ...]` against streamA char positions.

4. **Build TV-stem alignment stream:**
   - Concatenate all word.text into one string, romanize with `toHepburnRomaji`, then `normRomaji` → `streamB`.
   - **Build TV-time index:** `streamB_charToTimeMs[i]` = ms timing of the source word that owns char i (use word.start linearly interpolated across word.text length, OR — simpler — `word.start` for the FIRST char of each word and `word.end` for the LAST). Pick whichever maps to the existing `computeVerseTimes` expectation; document choice inline.

5. **Run NW:** `result = needlemanWunsch(streamA, streamB, {match:2, mismatch:-1, gap:-1})`.

6. **Per-verse projection (the core SPEC-REQ-2 logic):**
   - For each verseRange `{verseNumber, charStart, charEnd}` in streamA:
     - Walk `result.alignment`, find all entries where `aIndex >= charStart && aIndex <= charEnd && type === "match"`.
     - Compute `matchedChars = matches.length`, `verseLengthChars = charEnd - charStart`, `coverage = matchedChars / verseLengthChars`.
     - If `coverage < VERSE_PRESENCE_THRESHOLD` (0.40): mark verse as "no TV timing claim" — emit it with `start_time_ms: 0`, `end_time_ms: 0`, OR per old-10b convention. Document the choice; the goal is "no [no_detected_verses] outputs" per SPEC-REQ-2 acceptance — emit ALL verses, just with degraded timing for low-coverage ones.
     - If `coverage >= 0.40`: `tv_start_raw = streamB_charToTimeMs[firstMatch.bIndex]`, `tv_end_raw = streamB_charToTimeMs[lastMatch.bIndex]`.

7. **Apply gap-midpoint expansion:** call `computeVerseTimes(rawSpans)` (verbatim from old 10b) — tightens inter-verse boundaries by averaging adjacent verse end/start.

8. **Emit lesson:** clone the input lesson, overwrite each verse's `start_time_ms`/`end_time_ms` from the projection, leave all other lesson fields untouched.

9. **Validate:** `LessonSchema.safeParse(out)`; on failure print the error and skip writing.

10. **Write:** `data/lessons-cache-tv-nw/{slug}.json` (parallel dir per D-08). `mkdir -p` the directory if missing.
