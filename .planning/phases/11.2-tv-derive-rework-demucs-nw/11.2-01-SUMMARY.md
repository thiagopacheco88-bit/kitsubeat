## Deviations from Plan

### Intentional Divergences from ab-demucs-isolate.py Shape

**1. demucs.separate.main() vs subprocess -m demucs**
- **Found during:** Task 1 implementation
- **Issue:** The plan's action section specified `import demucs.separate` + `demucs.separate.main()`, but the reference script `ab-demucs-isolate.py` actually uses `subprocess.run([sys.executable, "-m", "demucs", ...])`. The acceptance criteria explicitly requires `import demucs.separate` in the file.
- **Fix:** Used `demucs.separate.main()` directly per acceptance criteria. Verified `demucs` is importable in the project venv. Added `SystemExit` handler since `demucs.separate.main()` calls `sys.exit()`.
- **Files modified:** scripts/seed/tv-demucs-isolate.py

**2. TV stems keep nested layout (not flattened)**
- The `ab-demucs-isolate.py` reference flattens `{model}/{slug}/vocals.wav` → `{slug}.wav` via `shutil.move`. TV scripts do NOT flatten — they preserve `data/vocal-stems-tv/htdemucs/{slug}/vocals.wav` as specified in D-01 and the plan's acceptance criteria.
- This means `tv-transcribe-stems.py` reads from the nested path `STEM_DIR/DEMUCS_MODEL/slug/vocals.wav` rather than a flat `STEM_DIR/slug.wav`.
