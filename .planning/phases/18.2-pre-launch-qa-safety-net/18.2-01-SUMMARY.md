## Decisions Made
- Used `test.describe.configure({ mode: 'serial' })` because running the 4 tests in parallel caused `ERR_TOO_MANY_REDIRECTS` from Clerk's dev-browser initialization competing across workers. Serial mode eliminates the race condition while keeping the spec deterministic.
- Navigate directly to locale-prefixed home page (`/pt-BR`, `/es`) instead of `goto('/')` with locale cookie. The `goto('/')` → 307 to `/pt-BR` redirect chain was triggering the Clerk dev-browser redirect loop under parallel load. Direct URL navigation avoids the redirect entirely.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Added serial mode and direct locale URL navigation to fix parallel execution flakiness**
- **Found during:** Task 1 (initial test run)
- **Issue:** Running 4 tests with default parallel workers caused `ERR_TOO_MANY_REDIRECTS` on `goto('/')` with locale cookie active. Root cause: Clerk dev-browser initialization across multiple simultaneous Playwright browser contexts creates a redirect race condition.
- **Fix:** (a) Added `test.describe.configure({ mode: 'serial' })` to run tests one at a time. (b) Changed `goto('/')` to `goto('/${prefix}')` to navigate directly to the locale-prefixed home page, avoiding the server-side redirect chain.
- **Files modified:** `tests/e2e/auth-reachability-locale.spec.ts`
