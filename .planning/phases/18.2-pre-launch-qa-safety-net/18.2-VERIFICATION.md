## Notable Deviations from Plan (Not Blocking)

### 1. auth-reachability-locale.spec.ts: href assertion instead of click-driven

The plan specified click-driven navigation (`page.getByRole('link', { name: /sign in/i }).first().click()`) and URL assertion (`toHaveURL('/sign-in')`). The implementation uses href attribute assertion (`getAttribute('href')` equals `/sign-in`) plus direct navigation to `/sign-in` with locale cookie.

**Cause:** Clerk dev-browser redirect races with parallel workers caused `ERR_TOO_MANY_REDIRECTS` when actually clicking and waiting for full navigation. Serial mode was added but even in serial mode, the click + navigation approach was flaky in dev mode.

**Impact:** The regression intent is preserved — the test confirms the Sign In link href is `/sign-in` (not `/pt-BR/sign-in`) and that `/sign-in` loads without 404 with a locale cookie set. The exact flow tested differs slightly from the real user journey (href check vs full click+navigation).

**Sign-up test absent:** The plan had a sign-up test (navigate to /sign-in, click "Don't have an account? Sign up", assert /sign-up URL). This test does not exist in the spec. Rationale: Clerk's sign-up link is inside the sign-in form which is server-rendered by Clerk; the test was dropped to avoid Clerk rendering timing dependency.

### 2. nav-sweep-all-locales.spec.ts: direct locale URL instead of cookie injection

The plan specified `context.addCookies` with kb_locale cookie; the implementation navigates directly to `/pt-BR` and `/es` locale home URLs instead. Functionally equivalent for extracting locale-aware nav hrefs, and avoids the Clerk dev-browser redirect race that affected plan 01.

### 3. ROADMAP SC-5 names `npm run test:qa`; implementation delivers `npm run test:e2e:qa`

The ROADMAP success criterion 5 and the phase goal description both say `npm run test:qa`. The implementation correctly avoided overwriting the existing `test:qa` (which runs the seed agent) and used `test:e2e:qa` instead. The CONTEXT.md (D-06) and all plans document this name collision and the rationale. The functional outcome is achieved — there is a single-command parallel Playwright runner — under the name `test:e2e:qa`.
