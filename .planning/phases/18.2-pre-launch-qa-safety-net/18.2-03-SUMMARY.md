## What Was Built

`tests/e2e/nav-sweep-all-locales.spec.ts` — 3 tests (one per locale: en no cookie, pt-BR, es) that:

1. Pre-set the locale cookie via `context.addCookies` (skipped for en)
2. Load the home page to get the rendered nav with locale-aware hrefs (next-intl localizes /songs → /pt-BR/songs etc.)
3. Extract all nav links dynamically via `page.getByRole('navigation').getByRole('link')`
4. Assert at least 2 links rendered (T-18.2-03-02 guard)
5. For each non-external, non-anchor href: `page.request.get(href)` → `toBeLessThan(500)`
6. Spot-check home body for no `'This page could not be found'` text

All 3 tests pass: 3 passed in ~48s with 3 parallel workers.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Removed over-tight page.goto timeout**
- **Found during:** Task 1 verification
- **Issue:** Plan specified `timeout: 10_000` on the initial `page.goto`. With 3 parallel workers all doing cold Next.js page loads simultaneously, the cold first load could exceed 10s and trigger spurious test failure.
- **Fix:** Removed the explicit timeout, delegating to the test-level timeout instead.
- **Files modified:** tests/e2e/nav-sweep-all-locales.spec.ts
- **Commit:** e146c68

**2. [Rule 1 - Bug] Added test.setTimeout(60_000) for loop-over-nav-links**
- **Found during:** Task 1 verification (all 3 tests timed out at 30s)
- **Issue:** The test makes one `page.goto` + ~7 `page.request.get` calls per locale. Each request takes 1-3s against the Next.js dev server. Total wall time can reach 24-25s, which exceeds the default 30s timeout when the server is under load.
- **Fix:** Added `test.setTimeout(60_000)` inside the describe block. This is not a flake — the test logic is correct; the timeout just needs headroom for the loop.
- **Files modified:** tests/e2e/nav-sweep-all-locales.spec.ts
- **Commit:** e146c68
