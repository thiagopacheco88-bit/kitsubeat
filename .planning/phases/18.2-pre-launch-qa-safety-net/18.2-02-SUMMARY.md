## Decisions Made

- Per-test timeout set to `{ timeout: 60_000 }` (overrides global 30 s) — locale redirect chains in Next.js dev mode can trigger route compilation on first access, taking 15–30 s; 60 s provides headroom without flaking
- `domain: 'localhost'` hardcoded in cookie injection, matching `baseURL: 'http://localhost:7000'` in playwright.config.ts (mitigates T-18.2-02-01)
- Import from `@playwright/test` directly (not from `tests/support/fixtures.ts`) — no DB deps needed for reachability checks

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Increased page.goto timeout and added per-test timeout override**
- **Found during:** Task 1 (verification run)
- **Issue:** Plan specified `timeout: 10_000` on `page.goto` but locale redirect chains in dev mode (/songs → /pt-BR/songs) triggered Next.js route compilation causing first-access times of 15–30 s. Tests failed non-deterministically.
- **Fix:** Set `page.goto` timeout to `30_000` and added `{ timeout: 60_000 }` per-test option (matching the established pattern in `journal-article.spec.ts`). The `beforeAll` warm-up approach was also tried but caused its own hook timeout issue; per-test timeout is simpler and matches codebase convention.
- **Files modified:** `tests/e2e/i18n-nav-locale-matrix.spec.ts`
- **Verification:** All 10 tests passed consistently with `--workers=1`
