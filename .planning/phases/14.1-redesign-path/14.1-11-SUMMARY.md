## Key Implementation Decisions

**h1 sr-only (W-7):** The `<h1 className="sr-only">Your Learning Path</h1>` is kept in the DOM
but visually hidden. PathHeader provides the visible wordmark + role="banner" chrome. The hidden
h1 satisfies axe-core's `page-has-heading-one` rule preemptively for Phase 14 SPEC AC #12
(axe ≥95 target).

**pb-32 column wrapper:** The `div.mx-auto.max-w-2xl` wrapper uses `pb-32` (128px bottom padding)
to prevent the sticky ContinueAnchor (fixed bottom-0, 56px height + 12px py) from overlapping
the last PathNode. Plan noted `pb-24` as an alternative; 128px is chosen for comfortable clearance.

**streakCurrent prop name (N-4):** `streakCurrent` (camelCase) is used consistently at the
`page.tsx -> PathHeader` call site: `streakCurrent={state.streak_current}`. The DB field is
`streak_current` (snake_case from drizzle schema); the conversion happens at the call site.
All existing PathHeader tests reference `streakCurrent`.

**B-4 nextReward.label derivation preserved byte-for-byte:**
```tsx
label:
  (nextReward.content as { label?: string }).label ??
  nextReward.slot_type,
```
This expression was in the pre-rewrite `page.tsx` feeding PathHud's chip. Plan 11 re-targets
it at HeroProgress without modification. Type-safe: all 3 active v3.0 RewardSlotContent variants
carry `label: string`; the `?? nextReward.slot_type` fallback is unreachable on the happy path.

**useSearchParams Suspense boundary (N-2):** The `/kana` page is a `"use client"` component.
`useSearchParams()` is valid in client components in Next.js 15 without a wrapping `<Suspense>`
boundary — the Suspense requirement applies only when `useSearchParams` is used in a Server
Component boundary or in a streaming layout. No Suspense boundary was added; TypeScript exits 0
and no runtime error occurs. If a future Next.js version emits a warning, wrap the component
export in `<Suspense fallback={<div className="animate-pulse" />}>`.

**isValidScriptParam allowlist (T-14.1.11-01):** Only `"hiragana"` and `"katakana"` are accepted
as script param values. `"mixed"` is intentionally excluded as a deep-link target — it is a
deliberate user-toggle action, not a bookmark-able state. Any other value (null, garbage, injection
attempt) falls back to `"hiragana"`. The param is consumed as a typed enum value and never
interpolated into a URL or filesystem path; no path traversal is possible.

**KanaCheckpointNode kana-row spacing:** The kana checkpoint row uses
`grid grid-cols-1 sm:grid-cols-2 gap-2 my-2`. On mobile (single-column) the two cards stack
vertically within the path's left-right alternating flow. On sm+ breakpoint they sit side-by-side.
This is consistent with the SPEC demo layout.
