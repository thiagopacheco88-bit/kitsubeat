# Phase 14.1 Plan 05: PathHeader Component Summary

PathHeader server component composing the KitsuBeat fox-mark wordmark (left) and LanternStreak (right), replacing the deleted PathHud on /path.

## What Was Built

`<PathHeader streakCurrent={number}>` — server component (no `"use client"`) rendering a horizontal header strip:

- **Left:** 26x26px fox-mark SVG + "KitsuBeat" wordmark text
- **Right:** `<LanternStreak count={streakCurrent} />`
- Root `<header>` element with `data-testid="path-header"` for E2E selection
- "Beat" emphasis via `text-[var(--color-accent)]` with `data-testid="wordmark-emphasis"`

## Demo Wordmark Treatment

The demo (`_temp/path-redesign/demo-CA-hybrid.html`, lines 258-269) includes:

1. **Fox-mark SVG** (26x26, viewBox 0 0 32 32): fox body ellipse + two ear polygons + two eye ellipses + nose ellipse. All fills use `var(--color-grammar-adverb)` (body/ears), `var(--color-text)` (eyes), `var(--color-accent)` (nose). Reproduced verbatim in JSX with token mapping.
2. **Wordmark text**: `fontWeight: 800, fontSize: 17, letterSpacing: '-0.01em'` — mapped to Tailwind `text-lg font-extrabold tracking-tight`. "Kitsu" in `text-[var(--color-text)]`, "Beat" in `text-[var(--color-accent)]`.

No fox-avatar (PathHud-style) — the fox-MARK is a different, smaller graphic used as a brand icon, per CONTEXT D-08 which drops only the full avatar.

## Exact "Beat" Emphasis className

```
text-[var(--color-accent)]
```

Located on `<span data-testid="wordmark-emphasis">Beat</span>` — grep this string for downstream styling tweaks.
