## SVG Icon Sourcing

**Demo paths were available and copied verbatim.** The `_temp/path-redesign/demo-CA-hybrid.html` TierIcon component (lines 168-193) provides all three icon shapes with `viewBox="0 0 24 24"` and `fill="none"` + `stroke="currentColor"` construction.

### Bamboo icon
- Dual vertical stalks with segment joints (`M9 2v4m0 4v4m0 4v4M15 2v3m0 5v3m0 5v3`)
- Ellipse node markers at each joint with `opacity="0.55"` for visual depth
- `fill="currentColor"` on ellipses, `stroke="currentColor"` on paths — all theme-aware

### Torii gate icon
- Kasagi + shimaki crossbeams: `M3 5h18M2 8h20` (strokeWidth 1.8)
- Hashira pillars: `M5 8v13M19 8v13`
- Nuki tie beam: `M5 11h14` (strokeWidth 1.4)

### Mountain icon
- Main ridge: `M2 20l6-10 4 6 3-4 7 8` (strokeWidth 1.8)
- Snow-cap highlights at each peak: `M6 14l2-3 2 3M14 12l1.5-2 1.5 2` at `opacity="0.5"`

## Light vs Dark Theme Rendering

The mountain "snow cap" highlight paths use `stroke="currentColor" opacity="0.5"` (not `fill="var(--color-bg)"` as the plan sketch suggested). This is correct: using `currentColor` means the highlights render as semi-transparent lines over the ridge in both themes, which is visually coherent and avoids any bg-color bleed. The bamboo ellipse nodes follow the same pattern. No theme-specific inversion needed since there are no fill-based snow caps.

## Bilingual Label Architecture

```
<div aria-label="Side A · 基礎 · Beginner">          ← full bilingual label for screen readers
  <div /> ← left rule
  <span>                                              ← chip (uppercase tracking, muted)
    <TierIcon kind="bamboo" />                        ← 16×16 SVG, aria-hidden
    <span>Side A</span>                               ← English side label
    <span style={fontFamily: var(--font-jp)}>基礎</span>  ← JP with Noto Sans JP + normal-case
    <span>Beginner</span>                             ← English tier name
  </span>
  <div /> ← right rule
</div>
```

The `normal-case` class on the JP span overrides the chip's `uppercase tracking-wide` parent rule, which would mangle Japanese characters.
