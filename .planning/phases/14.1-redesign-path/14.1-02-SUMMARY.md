## What Changed

### Task 1: getStarterSongs() — filter+warn (not throw)

Lines 106-112 of `starter-songs.ts` previously contained:

```ts
if (allMissing.length > 0) {
  throw new Error(`[starter-songs] getStarterSongs(): ...`);
}
```

Replaced with:
- `lessonedRows` computed via `.filter(r => r.has_lesson !== null && r.has_lesson !== 0)`
- All-drift branch: single `console.warn("[starter-songs] ALL approved starter slugs missing — rendering EmptyState fallback. ...")`
- Per-slug branch: one `console.warn("[starter-songs] {slug} missing or lessonless — filtered from starter pool")` per drifted slug
- Rebuild block: `STARTER_SONG_SLUGS.flatMap(...)` using `lessonedRowMap.get(slug)` with `if (!r) return []` guard — eliminates the `rowMap.get(slug)!` non-null assertion

### Task 2: StarterPick — EmptyState fallback

Added to `src/app/path/components/StarterPick.tsx`:
- `import { EmptyState } from "@/components/ui/EmptyState"` 
- Early-return guard `if (candidates.length === 0)` before `handleSelect` definition
- EmptyState: `heading="More starter songs coming soon"`, `body="Pick something from the full catalog while we restock your starter list."`, `ctaLabel="Explore the catalog"`, `ctaHref="/songs"`, `aria-label="No starter songs available"`
- Populated-branch JSX is byte-unchanged (verified via `git diff` — only import + early-return block added)
