## Implementation Details

### Panel Layout

The 38/62 split from the SPEC was matched exactly:
- Cover-art panel: `w-[38%] flex-shrink-0` (percentage-based to track parent width)
- Info panel: `flex-1 min-w-0` (fills remainder)
- Total height: 84px via `style={{ height: "84px" }}` (inline style used to satisfy lint)

### State Derivation

```ts
function deriveState(isCurrent: boolean, isCompleted: boolean): NodeState {
  if (isCurrent) return "current";     // precedence over completed
  if (isCompleted) return "mastered";  // completed === mastered per CONTEXT deferral
  return "locked";
}
```

**No in_progress state.** SongListItem has no star-mastery field. CONTEXT.md deferred record: "Precise 3-star mastery signal: deferred — currently mastered = completed; refine when star-mastery field is exposed on SongListItem."

### State Overlays

| State | Overlay | Class hook | Data signal |
|-------|---------|-----------|-------------|
| mastered | 3-star aura halo (top-right info panel) | `ka-aura` | `data-state="mastered"` |
| current | PLAY ▶ centered on cover panel | `ka-pulse` | `data-state="current"` |
| locked | Mist gradient covering full card | inline `pointerEvents: "none"` | `data-state="locked"` |

### M1 Invariant

- `CardLink variant="flat"` is the root in all 3 states
- No `disabled` attribute anywhere
- No `pointer-events: none` on the link itself
- Locked mist overlay sets `pointerEvents: "none"` via inline style so taps fall through

### Wave 1 Token Consumption

- `var(--mist-fill)` — locked-state mist background (linear-gradient from Plan 01 tokens)
- `var(--aura-color)` — mastered-state aura radial glow background (amber)
- `.ka-pulse` — PLAY ▶ overlay animation class (current state)
- `.ka-aura` — 3-star halo animation class (mastered state)
