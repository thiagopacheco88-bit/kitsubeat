# Phase 14.1 Plan 04: LanternStreak Component Summary

SVG paper lantern streak indicator with 3-tier flame intensity scaling, replacing the emoji in PathHud (deleted per CONTEXT D-06), ready for PathHeader composition.

## What Was Built

`LanternStreak` is a pure server component (no `"use client"`) that renders an inline SVG paper lantern with flame intensity that scales with the user's streak count. The component was authored TDD (RED commit then GREEN commit).

### Token Mappings

| Demo raw value | Token used | Reason |
|----------------|-----------|--------|
| `fill="#f59e0b"` (paper body) | `fill="var(--color-jlpt-n3)"` | Exact hex match for amber N3 color |
| `fill="#dc2626"` (flame core) | `fill="var(--color-accent)"` | Exact hex match for accent red |
| `fill="#fef3c7"` (inner glow) | `fill="currentColor"` | No cream/near-white token exists; currentColor adapts to both themes gracefully at reduced opacity |
| ribs, caps, outline | `currentColor` / `stroke="currentColor"` | Adapts to theme text color |

### Opacity Serialization

`flameOpacity()` returns a JavaScript `number`. React serializes these to DOM attribute strings as:
- `0.45` → `"0.45"` (getAttribute returns `"0.45"`)
- `0.7` → `"0.7"` (getAttribute returns `"0.7"`, NOT `"0.70"`)
- `1` → `"1"` (getAttribute returns `"1"`, NOT `"1.0"`)

Test assertions use `toBe("0.45")`, `toBe("0.7")`, and `opacity === "1" || opacity === "1.0"` (defensive check for both serializations).

### W-5 Testid Discipline

Two distinct testids are exposed:
- `data-testid="lantern-streak"` — on the outer `<span role="img">` root (whole component)
- `data-testid="lantern-streak-count"` — on the inner `<span>` containing only the `{count}` text

Plan 12 visual-diff specs will mask `[data-testid="lantern-streak-count"]` so the SVG lantern stays in the visual gate while dynamic streak count text is excluded from pixel comparison.

### SVG Geometry

Verbatim from `_temp/path-redesign/demo-CA-hybrid.html`. No geometric changes. viewBox=`0 0 22 26`, width=22, height=26.

Elements in z-order:
1. Top cap: `<rect x="6" y="2" width="10" height="2" rx="0.5">` + hanging line
2. Body fill: `<ellipse cx="11" cy="13" rx="7.5" ry="9">` — paper warm (var(--color-jlpt-n3))
3. Body outline: same ellipse, stroke only
4. Three bamboo ribs at y=9, y=13, y=17
5. Flame core: `<ellipse cx="11" cy="13" rx="3" ry="4.5">` — `className="ka-flicker"` + `data-testid="lantern-flame"` + `opacity={flameOpacity}`
6. Inner glow: `<ellipse cx="11" cy="13" rx="1.5" ry="2.5">` — currentColor, opacity * 0.85
7. Bottom cap: `<rect x="6" y="22" width="10" height="2" rx="0.5">`

## Deviations from Plan

None — plan executed exactly as written. SVG geometry taken verbatim from demo; all token mappings follow the plan's mapping instructions.
