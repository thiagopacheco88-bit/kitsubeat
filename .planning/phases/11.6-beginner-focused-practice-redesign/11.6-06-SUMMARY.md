## SSR All-Kana Detection

**Location:** `src/app/songs/[slug]/page.tsx` (lines 96-100)

```typescript
const hasKanjiBearingVocab = enrichedLesson.vocabulary.some(
  (entry) => hasKanji(entry.surface)
);
```

Computed once per version at SSR time (RESEARCH Pitfall 7 compliance). Passed via `VersionData.hasKanjiBearingVocab?` through SongContent to ExerciseTab as prop. Default is `true` (backwards-compatible fallback for any callsite that pre-dates this prop).

## tier.ts trackKind Extension

**Signature change:** `tierFor(state: number, trackKind?: string): Tier`

**Bypass logic:** Returns `TIER_NEW` immediately when `trackKind === "vocab" || trackKind === "grammar"`, before the existing switch statement. Existing callers that omit `trackKind` are unaffected.

**TierText implementation note:** The bypass in TierText.tsx is inline (not a call to `tierFor`) — `isTrackBypass` flag short-circuits before any tier computation, ensuring zero `tierFor()` calls for vocab/grammar render paths (verified by Test 5 in track-text-rendering.test.tsx).
