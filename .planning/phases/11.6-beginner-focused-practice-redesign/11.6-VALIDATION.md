## Sampling Rate

- **After every task commit:** Run `npm run test:unit` (covers lag-test solver, JLPT sort, vocab_typed normalization, kanji-track filter, three-ring math)
- **After every plan wave:** Run `npm run test:integration` + `npm run test:e2e` (covers DB writes + UI flows)
- **Before `/gsd-verify-work`:** `npm run test:all` must be green
- **Max feedback latency:** ~10s for unit-level signal during task work
