# Phase 11.6: Beginner-Focused Practice Redesign — Specification

**Created:** 2026-05-01

## Goal

Restructure the song-page practice flow into three parallel beginner-focused tracks (Vocabulary, Grammar, Kanji) — with romaji + translation as the teaching surface, ComfyUI-batched mnemonic images, dual FSRS cards per word, JLPT-ordered lag-tested scheduling, per-verse "dominated" state with inline animation, and an Advanced Drills entry gated behind ≥80% per-track progress.

## Background

The exercise engine is feature-complete (7 exercise types, 3-star mastery, FSRS persistence, /review cross-song SRS queue, per-song completion %), but the practice surface is misaligned for beginners:

- **Furigana is taught** in the standard Vocab + Grammar exercise flow (via [src/lib/fsrs/tier.ts](src/lib/fsrs/tier.ts) tier-based reveal). Beginners need romaji + translation as the primary signal — furigana is display-only ornament.
- **One FSRS card per word** in `user_vocab_mastery` — there is no separation between "I know what this word means" and "I can produce it from kanji/kana". Mastery in one collapses both.
- **Exercise scheduling is encounter-order** — `buildQuestions` in [src/lib/exercises/generator.ts](src/lib/exercises/generator.ts) emits questions per-vocab in vocab-list order, and an introduced word can be tested at the next position. No JLPT ordering, no lag.
- **Advanced Drills is per-exercise-type free-quota gated** (10 listening + 3 advanced drills) rather than per-song-progress gated.
- **No Kanji track** — `kanji_breakdown` ships in the FeedbackPanel accordion (Phase 08.3) but has no dedicated drill mode.
- **No per-verse mastery surface** — the song page shows aggregate completion % only; users cannot see which specific verses they have or have not "owned".
- **No ComfyUI image generation** — Phase 11.4 wires `vocabulary_items.image_url` infra and ships 50 hand-curated Unsplash CC0 images for concrete top-frequency vocab; the remaining ~1,360 words have no image.

This phase rebuilds the practice loop around the beginner romaji-first mental model, splits per-word mastery into two FSRS cards, adds a Kanji-only drill track with a mnemonic image per word, lands a verse-by-verse "domination" state with an inline animation, and replaces the per-quota Advanced Drills gate with a three-ring per-song-progress gate.

## Requirements

1. **Three-track ExerciseTab structure**: ExerciseTab presents Vocabulary, Grammar, and Kanji as the three primary mode cards, each with a Short / Long toggle.
   - Current: ExerciseTab shows three cards — standard exercises, Listening Drills (10-song free quota), Advanced Drills (3-song free quota); no track separation; no length toggle.
   - Target: ExerciseTab renders Vocabulary, Grammar, Kanji cards (in that order) plus an Advanced Drills card below them. Each track card has a Short/Long toggle. Today's per-exercise-type free-quota gating is removed.
   - Acceptance: Playwright loads `/songs/[slug]` exercise tab and asserts (a) four mode cards visible: Vocabulary, Grammar, Kanji, Advanced Drills; (b) each track card exposes a Short/Long toggle control; (c) no card references the strings "Listening Drills" or the previous mode names; (d) clicking Vocab/Grammar/Kanji starts a session of the corresponding track.

2. **Vocabulary + Grammar tracks teach romaji, not furigana**: In Vocab and Grammar exercise prompts, romaji + translation are the highlighted teaching signal; furigana is shown as an unobtrusive display ornament only (no tier-based reveal-as-progress mechanic in these tracks).
   - Current: Vocab and Grammar prompts use [src/lib/fsrs/tier.ts](src/lib/fsrs/tier.ts) which gates furigana → kanji-only based on FSRS state, treating furigana removal as a teaching milestone.
   - Target: Vocab and Grammar tracks render `kanji + small-furigana + romaji` consistently, with romaji as the visual emphasis. Tier-based reveal is disabled for these tracks. Furigana stays present (small, dim) at all FSRS states; correct answer reveals translation if not visible.
   - Acceptance: Render Vocab and Grammar question cards at 3 different FSRS states (new, learning, review); assert romaji is present and visually emphasized in all three; assert furigana is present in all three; assert no tier-class transition logic fires for these tracks.

3. **Kanji track is per-song and drills kanji-bearing vocab**: New Kanji track that drills only the song's vocab items containing at least one kanji, using the mnemonic image + kanji_breakdown as the teaching surface.
   - Current: No Kanji-only drill mode exists; `kanji_breakdown` is shown only in the FeedbackPanel "More" accordion (Phase 08.3).
   - Target: Clicking the Kanji card builds a session of questions drawn from this song's vocabulary_items where `surface` contains at least one kanji codepoint. Each question shows the mnemonic image + kanji_breakdown + meaning, asks the user to produce the kana reading (romaji-typed input).
   - Acceptance: For a test song with N kanji-bearing vocab, the Kanji session emits exactly N questions (short) or up to 2N (long); zero questions reference non-kanji-bearing words; FeedbackPanel shows the same image rendered on Vocab track for the same word (proves shared `image_url`).

4. **Dual FSRS cards per word**: Each vocabulary_item carries two FSRS cards — `romaji_meaning` (driven by Vocab track) and `kanji_kana` (driven by Kanji track) — tracked independently in `user_vocab_mastery`.
   - Current: `user_vocab_mastery` has one row per (user_id, vocab_item_id); `recordVocabAnswer` updates a single FSRS scalar set.
   - Target: `user_vocab_mastery` carries a `card_kind` discriminator (`romaji_meaning` | `kanji_kana`); primary key becomes (user_id, vocab_item_id, card_kind); `recordVocabAnswer` accepts a `cardKind` argument and routes to the correct row. Existing rows are wiped and recreated under `card_kind = 'romaji_meaning'` (per Q1.3 (b)).
   - Acceptance: Vitest integration test inserts a Vocab answer (correct) and a Kanji answer (incorrect) for the same vocab_item_id, asserts two distinct rows exist with diverged FSRS state; existing pre-migration rows are gone post-migration (`SELECT count(*) FROM user_vocab_mastery WHERE card_kind IS NULL` returns 0).

5. **JLPT-ordered question queue**: Within a session, questions are sorted N5 → N4 → N3 → N2 → N1, with `jlpt_level IS NULL` items emitted last.
   - Current: `buildQuestions` emits questions in vocab-list order then sentence_order then per-grammar-point — no JLPT sort.
   - Target: Final question array is stable-sorted by `jlpt_level` ascending (N5 first), with nulls last. Sort is preserved across track types.
   - Acceptance: Vitest unit test feeds a mixed-JLPT vocab list to `buildQuestions`; asserts the emitted question array's `jlpt_level` values are monotonically non-decreasing with nulls at the tail.

6. **Lag-tested scheduling with SRS interleave**: Within a session, a vocab item introduced (LearnCard) at index N is never tested before index N+3; new introductions are interleaved with same-track SRS-due review items when both are present.
   - Current: A LearnCard at index N is followed by the question for the same vocab at index N+1.
   - Target: After a LearnCard at position N, the same vocab's first question appears at position ≥ N+3; if review-queue items are due in this track, they interleave with new introductions rather than appearing as a separate block.
   - Acceptance: Vitest integration test builds a session with 3 new vocab + 7 SRS-due reviews; asserts (a) for every introduced vocab item, the index gap between LearnCard and first question ≥3; (b) the resulting sequence does not contain a contiguous block of 3 new followed by 7 reviews — at least one review appears within the first 5 items.

7. **Romaji-typing exercise variant**: A typing-input exercise type exists where the user types the romaji reading of a kanji/kana surface and the answer is checked via [src/lib/exercises/romaji-normalize.ts](src/lib/exercises/romaji-normalize.ts) tolerance (e.g., `benkyou` / `benkyō` / `benkyō` all accepted).

10. **Per-song advanced drills unlock = ≥80% per track**: Advanced Drills is gated by per-song progress: ≥80% of vocab items answered correctly ≥1 time in the romaji-meaning card AND ≥80% of grammar items answered correctly ≥1 time AND ≥80% of kanji-bearing items answered correctly ≥1 time in the kanji-kana card.
