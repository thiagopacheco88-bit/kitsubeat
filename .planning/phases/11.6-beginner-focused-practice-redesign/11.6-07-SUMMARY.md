## TrackProgressRings Component (88 lines)

### Key SVG Attributes

```tsx
// Fill animation — 600ms ease-out per RESEARCH §"Common Operation 2"
strokeDasharray={circumference}
strokeDashoffset={offset}  // = circumference * (1 - clamped/100)
strokeLinecap="round"
transform={`rotate(-90 ${size / 2} ${size / 2})`}
style={{ transition: "stroke-dashoffset 600ms ease-out, stroke 300ms" }}

// Glow drop-shadow when closed (pct >= 80)
className={isClosed ? "drop-shadow-[0_0_4px_rgba(251,191,36,0.5)]" : ""}

// Threat T-11.6-07-03 mitigation — clamp before division
const clamped = Number.isFinite(pct) ? Math.min(100, Math.max(0, pct)) : 0;
```

### Color Logic

| State | stroke color | drop-shadow |
|-------|-------------|-------------|
| pct < 80 | `#9CA3AF` (gray-400) | none |
| pct >= 80 | `#FBBF24` (amber-400) | `0 0 4px rgba(251,191,36,0.5)` |

## Pitfall 6 (numeric precision) Mitigation Evidence

Location: `src/app/songs/[slug]/page.tsx` — `progressMap` construction:

```typescript
vocab: row.vocab_track_pct != null
  ? parseFloat(row.vocab_track_pct as unknown as string)
  : 0,
```

Three-layer defense:
1. `Number.isFinite(pct)` check in `TrackProgressRing` clamps NaN/Infinity
2. `Math.min(100, Math.max(0, pct))` clamps to [0, 100]
3. Gate comparison `>= 80` (not `>= 80.00`) — per RESEARCH Pitfall 6

## Threat T-11.6-07-03 Mitigation Evidence

Location: `src/app/songs/[slug]/components/TrackProgressRings.tsx` — `TrackProgressRing` component:

```typescript
const clamped = Number.isFinite(pct) ? Math.min(100, Math.max(0, pct)) : 0;
```
