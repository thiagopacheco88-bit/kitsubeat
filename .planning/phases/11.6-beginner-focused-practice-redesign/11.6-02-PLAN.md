    Step 2 — implement `runFetch()`:
    - Read `UNSPLASH_ACCESS_KEY` from env; fail fast with a runbook message if unset.
    - Query for rows: `WHERE part_of_speech IN ('noun','verb','i_adjective','na_adjective') AND image_url IS NULL` (CONTEXT D-07).
    - Counters: `loaded`, `skipped` (no API match), `cached` (dedup hit), `rate_limited`, `errors`.
    - For each row:
      a. Build query: `meaningEn = localize(row.meaning as Localizable, 'en')`; `hint = row.part_of_speech === 'verb' ? 'action' : 'object'`; `query = `${meaningEn} (${hint})``.
      b. Check in-process dedup Map: if `meaningEnCache.has(meaningEn)`, reuse the cached URL → UPDATE row → increment `cached` counter → continue.
      c. Otherwise call `fetch('https://api.unsplash.com/search/photos?query=' + encodeURIComponent(query) + '&orientation=squarish&per_page=1', { headers: { Authorization: 'Client-ID ' + UNSPLASH_ACCESS_KEY } })`.
      d. On HTTP 429: read `response.headers.get('x-ratelimit-reset')`, parse as Unix seconds, compute `sleepMs = (reset * 1000) - Date.now() + 5000` (5-second buffer), `await new Promise(r => setTimeout(r, sleepMs))`, then retry the same row → increment `rate_limited` counter.

      f. On 200 with empty `results[]`: log + increment `skipped` + continue.
