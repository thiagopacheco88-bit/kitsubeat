## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSR data-load → ExerciseTab props | Page reads vocab + lesson at SSR time using existing authenticated query path. hasKanjiBearingVocab is server-computed; client cannot tamper. |
| ExerciseTab → ExerciseSession dispatch | trackKind + lengthMode are client-controlled; Zod-validated downstream by recordVocabAnswer (Plan 11.6-05) at the cardKind level. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11.6-06-01 | Tampering | trackKind / lengthMode passed from client to server with arbitrary value | mitigate | TypeScript narrowing at compile time.
