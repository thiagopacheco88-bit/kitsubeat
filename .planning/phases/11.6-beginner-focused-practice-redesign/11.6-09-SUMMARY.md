### Task 2: ExerciseSession dispatch + LearnCard modifications

**ExerciseSession changes:**
- New prop: `trackKind?: TrackKind` (defaults to `"vocab"`)
- Imports: `TrackKind`, `recordVocabAnswer`, `VocabTypedCard`
- `setVersesDominatedNow` from store (Plan 11.6-05 animation trigger)
- New handler `handleVocabTypedAnswered`:
  - Records in store (session progress)
  - Determines `cardKind`: `trackKind === "kanji"` → `"kanji_kana"`, else → `"romaji_meaning"`
  - Fire-and-forget `recordVocabAnswer` with cardKind
  - Propagates `result.versesDominatedNow` to store when non-empty
- New dispatch case `vocab_typed` → `<VocabTypedCard ... onAnswered={handleVocabTypedAnswered} lang={translationLang} />`
- `trackKind` prop passed through to `LearnCard`

**ExerciseTab changes:**
- New `activeTrackKind` state (defaults `"vocab"`)
- Set in `handleStart` when session begins
- Passed as `trackKind={activeTrackKind}` to ExerciseSession

**LearnCard changes:**
- New prop: `trackKind?: TrackKind`
- `isKanjiTrack = trackKind === "kanji"` derived bool
- `hasMoreContent` for Kanji track = `hasMnemonic` only (breakdown shown prominently, not in accordion)
- Prominent KanjiBreakdownSection block after meaning paragraph, `data-testid="learn-card-kanji-breakdown-prominent"`, only rendered when `isKanjiTrack && hasKanjiBreakdown`
- Accordion KanjiBreakdownSection guarded with `!isKanjiTrack` — Plan 08.3 behaviour preserved for Vocab/Grammar tracks
