
## Operator Runbook

### Prerequisites (one-time)

1. Clone ComfyUI: `git clone https://github.com/comfyanonymous/ComfyUI`
2. Download checkpoint: `huggingface.co/ByteDance/SDXL-Lightning` → `sdxl_lightning_4step.safetensors` → place in `ComfyUI/models/checkpoints/`
3. Optional fallback (4-7GB VRAM): `huggingface.co/stabilityai/sd-turbo` → `sd_turbo.safetensors`
4. Start ComfyUI: `python main.py --listen 127.0.0.1 --port 8188`

### Environment (.env.local)

```
COMFYUI_URL=http://127.0.0.1:8188
COMFYUI_OUTPUT_DIR=D:/ComfyUI/output   # absolute path to ComfyUI's output/ directory
```

### Run overnight batch

```bash
npm run gen-image
# Expected: [gpu-probe] VRAM=...MB -> model=sdxl_lightning_4step.safetensors steps=4
# Expected: [batch] Rows to process: ~1409
# Expected: [ok] <word> (<uuid>) for each generated image
```

### Retry a bad image

```bash
npm run gen-image -- --regenerate <vocab_item_id>
# Regenerates one image regardless of existing image_url
```

### Verify completion

```sql
SELECT count(*) FROM vocabulary_items WHERE image_url IS NULL;
-- Should return 0 when batch is complete (SPEC-REQ-8 acceptance)
```

### Vercel Deploy Gotcha

`public/vocab-images/` is gitignored. For Vercel deploy, images must be served from a CDN or object storage (e.g., Vercel Blob, S3). The gitignore exclusion is correct for development — production deployment will need a separate upload step. This is tracked for Plan 11.6-12 (or a follow-up plan).

## Decisions Made

- **Use `dictionary_form` + `localize(meaning as Localizable, "en")`**: The plan interfaces spec mentioned `surface` and `meaning_en` columns, but the actual schema has `dictionary_form` and a JSONB `meaning` field (matching 11-enrich-vocab.ts precedent). Fixed as Rule 1 auto-fix.
- **EXDEV-safe pattern**: readFileSync + writeFileSync instead of copyFileSync, per RESEARCH §Pitfall 2 — cross-volume filesystem scenario.
- **ensureLoopback() at startup**: Reject any COMFYUI_URL that isn't 127.0.0.1/localhost/::1 to prevent accidental LAN exposure (T-11.6-02-01).
