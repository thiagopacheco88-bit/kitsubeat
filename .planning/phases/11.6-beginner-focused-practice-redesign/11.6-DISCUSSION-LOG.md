## ComfyUI Batch + Image Style

| Option | Description | Selected |

## Scheduler Algorithm

### D1 — Lag-test enforcement strategy

| Option | Description | Selected |
|--------|-------------|----------|
| (a) Pre-compute full session sequence at session start | Stable order; deterministic; resume-friendly | ✓ |
| (b) Incremental scheduler | Picks next question dynamically; can paint into corners | |
| (c) Hybrid | Pre-compute intros, dynamic distractors | |

**User's choice:** (a)
**Rationale:** Stable order; deterministic for Vitest assertions; constraint solver is small (≤30 items per session); plays nice with session-resume from refresh.

---

### D2 — JLPT-order vs lag-test conflict

| Option | Description | Selected |
|--------|-------------|----------|
| (a) Lag strict + JLPT best-effort | Lag is invariant; JLPT sorts within constraint envelope | ✓ |
| (b) JLPT strict + lag relaxed to ≥2 | Easier-first wins | |
| (c) JLPT strict + lag bypassed | Contradicts user's earlier lag-test priority | |

**User's choice:** (a)
**Rationale:** Lag-test is a learning-correctness invariant ("don't quiz on what you just saw"); JLPT is a UX preference. Constraints leave enough slack.

---

### D3 — Interleave strategy with SRS-due

| Option | Description | Selected |
|--------|-------------|----------|
| (a) Adaptive — due reviews first, fill with capped new | Matches Anki/FSRS philosophy | ✓ |
| (b) Fixed ratio (1 new : 2 review) | Predictable but ignores due volume | |
| (c) Random shuffle of new + due | Loses the "overdue matters more" SRS principle | |

**User's choice:** (a)
**Rationale:** Phase 11's /review queue already implements "all due + capped new" — same model. New cards stay capped by `users.new_card_cap`.

---

### D4 — Session length

| Option | Short / Long | Description | Selected |
|--------|--------------|-------------|----------|
| (a) 10 / 25 | Uniform across tracks; Long is a cap, not a target | ✓ |
| (b) 5 / 15 | Micro-sessions; harder to make meaningful progress | |
| (c) 7 / 20 | Splits the difference; 7 awkward | |
| (d) Per-track tuned | Vocab 10/25, Grammar 8/20, Kanji 10/25 | |

**User's choice:** (a)
**Rationale:** Consistency lets users develop expectation ("Short is always 10"); aligns with Phase 9 kana's 20-question fixed cadence; small grammar pools don't pad with noise.
