    ```bash
    # Option B — backgrounded (recommended; survives shell logout on Linux/macOS):
    nohup npm run fetch-images > fetch-images-$(date +%Y%m%d-%H%M).log 2>&1 &
    # Tail the log:
    tail -f fetch-images-*.log
    ```
    Expected runtime: ~22-28 hours at demo-tier 50 req/hr. The script logs `[429] sleeping Ns` whenever it hits rate limit — this is expected, not an error.
