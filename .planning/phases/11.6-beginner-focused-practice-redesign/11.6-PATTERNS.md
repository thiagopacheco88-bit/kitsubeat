### Idempotent SQL writes via `ON CONFLICT`
**Source:** `src/app/actions/review.ts:65-80` (consumeNewCardBudget) + `src/app/actions/exercises.ts:715-746` (recordVocabAnswer FSRS upsert) + `drizzle/0015_admin_lyrics_editor.sql:13-15` (enum guard)
**Apply to:** Migration 0016 (DDL guards), `recordVocabAnswer` (FSRS upsert + verse-domination INSERT + per-track-pct upsert), `user_song_progress` updates
```sql
INSERT INTO ... VALUES (...)
ON CONFLICT (composite_key) DO UPDATE SET ...
RETURNING ...
```
→ Critical for verse-domination: `ON CONFLICT DO NOTHING RETURNING verse_number` is the SQL-level idempotency that drives the once-per-(user,verse) animation guarantee (RESEARCH Pitfall 3).

### Per-row commit (NO transaction wrapper)
**Source:** `scripts/seed/19b-load-vocab-images.ts:69-74` + comment "Per-row commit — partial progress survives crashes (matches 11-enrich-vocab.ts:152-158)"
**Apply to:** `scripts/seed/20-comfyui-batch-images.ts`
**Rationale:** ComfyUI batch is ~90 min wall-clock. Operator-initiated Ctrl-C or GPU OOM mid-batch must leave already-generated images intact. Each row's UPDATE commits independently.

### Inline SVG icon (no chart libs, no icon packages)
**Source:** `src/app/songs/components/BonusBadgeIcon.tsx` (33-line precedent) + `src/app/songs/components/SongMasteredBanner.tsx` (32-line precedent) + `src/app/songs/[slug]/components/StarDisplay.tsx` (filled/outline star paths)
**Apply to:** `VerseStarIcon.tsx`, `TrackProgressRings.tsx`
**Rationale:** Bundle budget (50KB gzipped per Phase 13). Chart libs (recharts/Chart.js) add 30-50KB. Inline SVG is ~200B–1KB.

### canvas-confetti dynamic import
**Source:** `src/app/songs/[slug]/components/StarDisplay.tsx:31-45`
**Apply to:** `VerseDominatedAnimation.tsx`, `FeedbackPanel.tsx` animation trigger
```tsx
void import("canvas-confetti").then(({ default: confetti }) => {
  confetti({
    particleCount: 50,
    spread: 70,
    origin: { x: ..., y: ... },
    colors: ["#FBBF24", "#F59E0B", "#FCD34D"],
    disableForReducedMotion: true,
  });
});
```
→ Keeps confetti out of the SSR bundle. `disableForReducedMotion: true` honors `prefers-reduced-motion` automatically (RESEARCH "Don't Hand-Roll").
